# 1DEX1 — бот для личных переписок в Telegram

**@my1dex1_bot** работает прямо в твоих личных чатах через «Автоматизацию чатов»
(бывший Telegram Business). С мая 2026 (Bot API 10.0) для этого **не нужен Telegram Premium**.

## Что умеет

Команды пишешь **сам, прямо в переписке с человеком**:

| Команда | Что делает |
|---|---|
| `.mute` / `.mute 10m` | Мут собеседника: бот удаляет все его новые сообщения (у обоих). Время: `30s`, `10m`, `2h`, `1d`, `1h30m`, `1 минуту`, просто число = минуты, без времени = навсегда. Плашка «🔇 Собеседник в муте» с кнопкой «🔊 Размутить» — нажать её можешь только ты. Одноразовые фото/видео бот удалить не может: Telegram их ботам не показывает. |
| `.unmute` | Снять мут. |
| `.spam 20 текст` | Отправить текст 20 раз (лимит в `.env`). `.stop` — остановить. |
| `.unmuteme` | Антимут, если тебя замутили **другим** ботом: бот сразу дублирует каждое твоё сообщение от твоего имени и удаляет оригинал. Чужой бот «удаляет» оригинал, а копия остаётся. Работает против мут-ботов, которые реагируют только на первое сообщение. Если чужой бот удаляет и копии, наш переотправит сообщение ещё пару раз и сдастся, чтобы не было бесконечной войны ботов. Выключить: `.unmuteme off`. |
| `.link ссылка` | Видео из TikTok (без водяного знака), YouTube или VK Видео прямо в чат. |
| `.love` / `.love текст` | Анимация: сердечки собираются в сетку 7×5, по ней проходит радуга, в центре печатается твой текст (без текста — «сладких снов»). |
| `.rose текст` | То же с розами 🌹 и волной цветения. |
| `.fire текст` | Пламя 🔥 поднимается снизу, в центре — текст. |
| `.heart текст` | Большое пиксельное сердце с сердцебиением, текст под ним. |
| `.type текст` | Печатная машинка с мигающим курсором. |
| `.glitch текст` | «Битый» глитч-текст, который собирается в нормальный. |
| `.loading текст` | Полоска загрузки 0…100%, в конце твой текст. |
| `.mock` | Ответь на сообщение — бот перепишет его «пРиВеТ кАк ДеЛа». Или `.mock текст`. |
| `.music название` | Найти трек (YouTube, если не вышло — SoundCloud) и прислать mp3 в чат. Можно и ссылкой. В личке с ботом — `/music название`. |
| `.weather город` | Погода карточкой (Open-Meteo, запасной — wttr.in). Город по умолчанию — `WEATHER_CITY` в `.env`. |
| `.currency 100 usd` | Курс валют: `.currency` — курсы ЦБ к рублю, `.currency 100 usd`, `.currency 50 евро в доллары`, `.курс 5к рублей в тенге`. |
| `.time Токио` | Сколько сейчас времени в городе и на сколько это отличается от тебя. |
| `.rain текст` | Дождь, потом выходит солнце и радуга, в центре текст. |
| `.firework текст` | Салют 🎆. |
| `.rainbow текст` | Текст переливается радугой. |
| `.wave текст` | Текст «плывёт» волной заглавных букв. |
| `.stats` | Статистика переписки с этим человеком: кто больше пишет, средняя длина, кто быстрее отвечает, медиа, голосовые, самый активный день, сколько раз собеседник правил и удалял. Считается с момента, как бот запущен. |
| `.save` | Ответь этим на фото/видео/кружок/голосовое — бот пришлёт копию тебе в личку. Сама команда исчезнет из чата. |
| `.stop` | Остановить спам, анимацию или загрузку в этом чате. |
| `.help` | Шпаргалка (придёт в личку с ботом). |

Работает само:

* ✏️ **Изменённые сообщения.** Если собеседник отредактирует сообщение, бот пришлёт тебе в личку его ник,
  @юзернейм, начальный текст и изменённый текст. Много правок подряд (например, чужая анимация)
  склеиваются в одно уведомление.
* 🗑 **Удалённые сообщения.** Если собеседник удалит сообщения, бот пришлёт, что там было: текст —
  одним уведомлением, фото/видео/голосовые — файлами. То, что удалил сам бот (мут, антимут),
  не присылается. Бот не знает, кто именно удалил, поэтому если ты сам удалишь сообщение
  собеседника «у обоих», оно тоже придёт. Выключается в `/status`.
* 🔥 **Одноразовые фото, видео, кружки и голосовые.** Ответь на такое сообщение **до того, как откроешь**
  (свайп влево, любой текст), и бот пришлёт копию в личку как обычное медиа. Её можно сохранить.
  Одноразовость бот определяет точно по типу файла, на обычные фото он не реагирует.
* В личке с ботом можно просто кинуть ссылку на TikTok / YouTube / VK, и бот пришлёт видео.

### 📋 Меню команд

Напиши `@my1dex1_bot` в любой переписке — всплывёт список всех команд с подсказками. Нажми нужную, и бот
сразу её выполнит. Текст дописывается прямо в строке: `@my1dex1_bot love я скучаю`. Ещё в `/start`
есть кнопка «📋 Меню команд в переписке».

Telegram не даёт ботам показывать подсказки на «.» в переписке с человеком, поэтому меню открывается
через `@my1dex1_bot`. Чтобы оно заработало, один раз включи inline-режим:
`@BotFather` → `/setinline` → `@my1dex1_bot` → напиши подсказку, например `команда…`.

### 🎂 День рождения

27 января (настройка `BIRTHDAY` в `.env`) в 00:00 по твоему времени бот пришлёт тебе в личку анимированное
поздравление. За день он запомнит, кто тебя поздравил («с др», «с днём рождения», «happy birthday»…),
и в 23:00 пришлёт список с их сообщениями. Команды для этого нет — всё само. Посмотреть поздравление
заранее: скрытая команда `/bdaytest` в личке с ботом.

Команды можно писать и по-русски: `.мут`, `.размут`, `.спам`, `.антимут`, `.ссылка`, `.люблю`, `.розы`,
`.огонь`, `.сердце`, `.печать`, `.глитч`, `.загрузка`, `.дождь`, `.салют`, `.радуга`, `.волна`, `.мок`,
`.погода`, `.курс`, `.время`, `.музыка` / `.трек`, `.стата`, `.стоп`.

## Почему одноразовые сохраняются по ответу, а не сами

Сервер Bot API **никогда** не передаёт ботам одноразовые сообщения: в исходниках `telegram-bot-api`
стоит `if (message_info->is_self_destruct) return true;`. Но если ты **отвечаешь** на такое сообщение,
оно целиком приходит боту внутри ответа (`reply_to_message`), и бот его сохраняет. Так работают все боты
из TikTok, а те, кто пишет «полностью автоматически», путают одноразовые медиа с таймером автоудаления.

## Установка за 5 шагов

### 1. Включи Secretary Mode в @BotFather

`@BotFather` → `/mybots` → `@my1dex1_bot` → **Bot Settings** → **Secretary Mode** → включить.
(Этот режим ещё может называться **Chat Access Mode**, раньше — **Business Mode**. Если в меню чата
BotFather его нет, открой BotFather Mini App → свой бот → настройки.)
Без этого бота нельзя подключить к аккаунту. При запуске бот сам напишет в логе, если режим выключен.

### 2. Положи токен в `.env`

Скопируй `.env.example` в `.env` и впиши `BOT_TOKEN=...`.
Токен **никогда** не коммить в git и не показывай людям (`.env` уже в `.gitignore`).
Если токен где-то засветился, сделай в @BotFather `/revoke` и вставь новый.

### 3. Запусти бота

**Windows (проще всего):** установи [Python 3.11+](https://www.python.org/downloads/) (галочка «Add to PATH»)
и дважды кликни `run.bat`. Для `.link` с YouTube/VK ещё нужен [ffmpeg](https://www.gyan.dev/ffmpeg/builds/)
в PATH; для TikTok он не обязателен.

**Linux / VPS:**

```bash
./run.sh
```

**Docker (лучше всего для сервера 24/7):**

```bash
docker compose up -d --build
docker compose logs -f
```

Бот работает, пока запущен. Чтобы он был онлайн всегда, запусти его на VPS или на ПК, который не выключается.

**Android-телефон (Termux):** см. раздел [«Запуск на телефоне»](#запуск-на-телефоне-android) ниже.

### Запуск на телефоне (Android)

Пользоваться командами можно с любого телефона, где есть Telegram. А *запустить* самого бота можно на
Android через Termux. На iPhone так не выйдет: iOS не даёт программам работать в фоне.

1. Поставь **Termux** из [F-Droid](https://f-droid.org/packages/com.termux/) или с GitHub.
   Версия из Google Play устарела и не работает.
2. В Termux выполни по очереди (внутри ставится Debian, поэтому ничего не надо компилировать):

   ```bash
   pkg update -y && pkg install -y proot-distro
   proot-distro install debian
   proot-distro login debian
   ```

3. Теперь ты внутри Debian. Ставим бота:

   ```bash
   apt update && apt install -y python3 python3-venv git ffmpeg nano
   git clone --depth 1 --filter=blob:none --sparse -b ccr-f620085a-dcw2yg https://github.com/Mbrotororo/1DEX1-.git
   cd 1DEX1- && git sparse-checkout set 1dex1-bot && cd 1dex1-bot
   cp .env.example .env
   nano .env        # впиши BOT_TOKEN=..., сохрани: Ctrl+O, Enter, выйти: Ctrl+X
   ./run.sh         # первый запуск ставит зависимости (несколько минут)
   ```

4. Чтобы Android не убивал бота: потяни шторку уведомлений → в уведомлении Termux нажми
   **Acquire wakelock**, а в настройках телефона включи для Termux батарею
   **«Без ограничений»**.

Следующие запуски: открыть Termux → `proot-distro login debian` → `cd 1DEX1-/1dex1-bot && ./run.sh`.
Обновить бота: `git pull` в той же папке.

Важно: бот должен быть запущен **в одном месте**. Если он одновременно запущен на телефоне и на ПК,
Telegram выдаст ошибку `Conflict: terminated by other getUpdates request`.
Если телефон выключится или останется без интернета, бот тоже перестанет работать
(муты не будут удалять сообщения). Для работы 24/7 надёжнее VPS.

### 4. Подключи бота к своему аккаунту

Telegram → **Настройки** → **Автоматизация чатов** (в старых версиях: Telegram для бизнеса → Чат-боты) →
впиши `@my1dex1_bot` → выбери чаты (лучше все) → в правах на сообщения включи **всё**:

* **отвечать на сообщения** — нужно для всех команд;
* **читать сообщения**;
* **удалять отправленные ботом**;
* **удалять все сообщения** — нужно для `.mute`, `.unmuteme`, `.save` и чтобы команды исчезали.

Бот сам напишет тебе в личку, что подключён, и покажет, каких прав не хватает.

### 5. Нажми «Старт» в @my1dex1_bot

Там `/status`: статус, права и настройки (уведомления о правках и сохранение одноразовых можно выключить).

## Обновление бота

В папке бота (на телефоне — внутри `proot-distro login debian`):

```bash
cd ~/1DEX1-/1dex1-bot
git pull
./run.sh
```

Перед этим останови запущенного бота (`CTRL`+`c`). Настройки в `.env` и база в `data/` при обновлении
не трогаются; новые настройки из `.env.example` можно дописать в `.env` при желании —
без них работают значения по умолчанию.

## Ограничения Telegram (их не обойти)

* Писать в чат (команды, спам, антимут, анимации) бот может, только если **собеседник писал тебе
  за последние 24 часа**. Так Telegram ограничивает всех бизнес-ботов.
* Своё сообщение бот может редактировать (плашки, `.love`) в течение 48 часов после отправки.
* Видео для `.link` — до 50 МБ (лимит Bot API). Сохранение одноразовых: фото всегда, видео до 20 МБ
  скачиванием; больше 20 МБ бот пробует переслать напрямую.
* YouTube часто блокирует серверные IP («Sign in to confirm you're not a bot»). Дома такого обычно нет;
  на VPS положи cookies YouTube в файл (формат Netscape) и укажи путь в `YTDLP_COOKIES`.
* Бизнес-ботов у аккаунта может быть подключено только **один**.
* Изменённые и удалённые сообщения бот покажет, только если видел оригинал (бот был запущен, когда
  его прислали). Кэш хранится `CACHE_DAYS` дней в `data/bot.sqlite3` **только у тебя**, никуда не отправляется.
  Для `.weather` в погодный сервис уходит только название города, для `.music` в YouTube/SoundCloud —
  только поисковый запрос.

## Настройки (`.env`)

| Переменная | По умолчанию | Что это |
|---|---|---|
| `BOT_TOKEN` | — | токен от @BotFather |
| `ALLOWED_USER_IDS` | пусто (все) | **Впиши свой ID** — ID через запятую, кому можно пользоваться ботом. Свой ID бот покажет по `/start`. Если там опечатка, бот не запустится и напишет, что не так (чтобы случайно не открыться всем). |
| `SPAM_LIMIT` / `SPAM_DELAY` | 100 / 0.5 | лимит и пауза для `.spam` |
| `LOVE_FRAME_DELAY` | 0.7 | пауза между кадрами `.love` |
| `CACHE_DAYS` | 7 | сколько хранить тексты сообщений для «было → стало» и удалённых |
| `TZ_OFFSET` | 3 | твой часовой пояс относительно UTC (Москва = 3) — для «сегодня / за неделю» в `.stats` |
| `WEATHER_CITY` | пусто | город для `.weather` и `.time` без названия |
| `BIRTHDAY` / `OWNER_NAME` | 27.01 / 1DEX1 | твой день рождения (ДД.ММ, `off` — выключить) и как к тебе обращаться в поздравлении |
| `MAX_VIDEO_MB` / `MAX_VIDEO_MINUTES` | 50 / 20 | ограничения `.link` (больше 50 МБ Telegram ботам загружать не даёт) |
| `MAX_AUDIO_MINUTES` | 15 | максимальная длина трека для `.music` |
| `TIKTOK_HD` | 0 | 1 = TikTok в 1080p (HEVC), 0 = 540p H.264 (играет везде) |
| `YTDLP_COOKIES` | пусто | файл cookies для YouTube (положи его в `data/`, например `data/cookies.txt`; в Docker — `/app/data/cookies.txt`) |
| `YTDLP_JS_RUNTIME` | авто | JS-движок для YouTube. По умолчанию берётся `deno` из `requirements.txt`; можно указать `node` (нужен 22+) или `deno:/путь/к/deno` |

## Для разработчика

```text
bot/
  __main__.py      запуск, фоновые задачи (снятие мутов по таймеру, чистка кэша)
  core.py          обёртки над Bot API: ретраи при флуде, «ответ вместо команды», фоновые задачи
  db.py            SQLite + кэш в памяти (муты проверяются без обращения к диску)
  media.py         копии сообщений (антимут) и сохранение медиа в личку
  downloader.py    yt-dlp: TikTok без водяного знака, YouTube, VK
  animations.py    кадры .love
  texts.py         все тексты бота
  handlers/
    business.py    команды, мут, антимут + сторож удалений, одноразовые
    edits.py       уведомления о правках
    connection.py  подключение/отключение и права
    private.py     /start, /status, настройки, ссылки в личке
tests/             фейковый Telegram API + сквозные сценарии
```

pip install -r requirements-dev.txt
