# 1DEX1 — бот для личных переписок в Telegram

**@my1dex1_bot** работает прямо в твоих личных чатах через «Автоматизацию чатов»
(бывший Telegram Business). С мая 2026 (Bot API 10.0) для этого **не нужен Telegram Premium**.

## Что умеет

Команды пишешь **сам, прямо в переписке с человеком**:

| Команда | Что делает |
|---|---|
| `.mute` / `.mute 10m` | Мут собеседника: бот удаляет все его новые сообщения (у обоих). Время: `30s`, `10m`, `2h`, `1d`, `1h30m`, просто число = минуты, без времени = навсегда. Плашка с кнопкой «🔊 Размутить» — нажать её можешь только ты. |
| `.unmute` | Снять мут. |
| `.spam 20 текст` | Отправить текст 20 раз (лимит в `.env`). `.stop` — остановить. |
| `.unmuteme` | Антимут: если тебя замутили **другим** ботом, твои сообщения всё равно доходят. Бот сразу дублирует каждое твоё сообщение от твоего имени, а оригинал удаляет. Чужой бот «удаляет» оригинал, а копия остаётся. Выключить: `.unmuteme off`. |
| `.link ссылка` | Видео из TikTok (без водяного знака), YouTube или VK Видео прямо в чат. |
| `.love` / `.love текст` | Анимация: сердечки собираются в сетку 7×5, по ней проходит радуга, в центре печатается «сладких снов» (или твой текст). |
| `.save` | Ответь этим на фото/видео/кружок/голосовое — бот пришлёт копию тебе в личку. Сама команда исчезнет из чата. |
| `.stop` | Остановить спам или анимацию в этом чате. |
| `.help` | Шпаргалка (придёт в личку с ботом). |

Работает само:

* ✏️ **Изменённые сообщения.** Если собеседник отредактирует сообщение, бот пришлёт тебе в личку его ник,
  @юзернейм, начальный текст и изменённый текст.
* 🔥 **Одноразовые фото, видео, кружки и голосовые.** Ответь на такое сообщение **до того, как откроешь**
  (свайп влево, любой текст), и бот пришлёт копию в личку как обычное медиа. Её можно сохранить.
  Одноразовость бот определяет точно по типу файла, на обычные фото он не реагирует.
* В личке с ботом можно просто кинуть ссылку на TikTok / YouTube / VK, и бот пришлёт видео.

Также пишет команды по-русски: `.мут`, `.размут`, `.спам`, `.антимут`, `.ссылка`, `.люблю`, `.стоп`.

## Почему одноразовые сохраняются по ответу, а не сами

Сервер Bot API **никогда** не передаёт ботам одноразовые сообщения: в исходниках `telegram-bot-api`
стоит `if (message_info->is_self_destruct) return true;`. Но если ты **отвечаешь** на такое сообщение,
оно целиком приходит боту внутри ответа (`reply_to_message`), и бот его сохраняет. Так работают все боты
из TikTok, а те, кто пишет «полностью автоматически», путают одноразовые медиа с таймером автоудаления.

## Установка за 5 шагов

### 1. Включи Secretary Mode в @BotFather

`@BotFather` → `/mybots` → `@my1dex1_bot` → **Bot Settings** → **Secretary Mode** (раньше «Business Mode») → включить.
Без этого бота нельзя подключить к аккаунту. При запуске бот сам напишет в логе, если режим выключен.

### 2. Положи токен в `.env`

Скопируй `.env.example` в `.env` и впиши `BOT_TOKEN=...`.
Токен **никогда** не коммить в git и не показывай людям (`.env` уже в `.gitignore`).
Если токен где-то засветился, сделай в @BotFather `/revoke` и вставь новый.

### 3. Запусти бота

**Windows (проще всего):** установи [Python 3.11+](https://www.python.org/downloads/) (галочка «Add to PATH»)
и дважды кликни `run.bat`. Для `.link` с YouTube/VK ещё нужен [ffmpeg](https://www.gyan.dev/ffmpeg/builds/)
в PATH; для TikTok он не обязателен.

**Linux / VPS:**

```bash
./run.sh
```

**Docker (лучше всего для сервера 24/7):**

```bash
docker compose up -d --build
docker compose logs -f
```

Бот работает, пока запущен. Чтобы он был онлайн всегда, запусти его на VPS или на ПК, который не выключается.

### 4. Подключи бота к своему аккаунту

Telegram → **Настройки** → **Автоматизация чатов** (в старых версиях: Telegram для бизнеса → Чат-боты) →
впиши `@my1dex1_bot` → выбери чаты (лучше все) → в правах на сообщения включи **всё**:

* **отвечать на сообщения** — нужно для всех команд;
* **читать сообщения**;
* **удалять отправленные ботом**;
* **удалять все сообщения** — нужно для `.mute`, `.unmuteme`, `.save` и чтобы команды исчезали.

Бот сам напишет тебе в личку, что подключён, и покажет, каких прав не хватает.

### 5. Нажми «Старт» в @my1dex1_bot

Там `/status`: статус, права и настройки (уведомления о правках и сохранение одноразовых можно выключить).

## Ограничения Telegram (их не обойти)

* Писать в чат (команды, спам, антимут, анимации) бот может, только если **собеседник писал тебе
  за последние 24 часа**. Так Telegram ограничивает всех бизнес-ботов.
* Своё сообщение бот может редактировать (плашки, `.love`) в течение 48 часов после отправки.
* Видео для `.link` — до 50 МБ (лимит Bot API). Сохранение одноразовых: фото всегда, видео до 20 МБ
  скачиванием; больше 20 МБ бот пробует переслать напрямую.
* YouTube часто блокирует серверные IP («Sign in to confirm you're not a bot»). Дома такого обычно нет;
  на VPS положи cookies YouTube в файл (формат Netscape) и укажи путь в `YTDLP_COOKIES`.
* Бизнес-ботов у аккаунта может быть подключено только **один**.
* Изменённые сообщения бот покажет, только если видел оригинал (бот был запущен, когда его прислали).
  Кэш хранится `CACHE_DAYS` дней в `data/bot.sqlite3` **только у тебя**, никуда не отправляется.

## Настройки (`.env`)

| Переменная | По умолчанию | Что это |
|---|---|---|
| `BOT_TOKEN` | — | токен от @BotFather |
| `ALLOWED_USER_IDS` | пусто (все) | ID через запятую, кому можно пользоваться ботом. Свой ID бот покажет по `/start`. |
| `SPAM_LIMIT` / `SPAM_DELAY` | 100 / 0.5 | лимит и пауза для `.spam` |
| `LOVE_FRAME_DELAY` | 0.7 | пауза между кадрами `.love` |
| `CACHE_DAYS` | 7 | сколько хранить тексты сообщений для «было → стало» |
| `MAX_VIDEO_MB` / `MAX_VIDEO_MINUTES` | 50 / 20 | ограничения `.link` |
| `TIKTOK_HD` | 0 | 1 = TikTok в 1080p (HEVC), 0 = 540p H.264 (играет везде) |
| `YTDLP_COOKIES` | пусто | файл cookies для YouTube |
| `YTDLP_JS_RUNTIME` | авто | `node` или `deno`, нужен yt-dlp для YouTube |

## Для разработчика

```text
bot/
  __main__.py      запуск, фоновые задачи (снятие мутов по таймеру, чистка кэша)
  core.py          обёртки над Bot API: ретраи при флуде, «ответ вместо команды», фоновые задачи
  db.py            SQLite + кэш в памяти (муты проверяются без обращения к диску)
  media.py         копии сообщений (антимут) и сохранение медиа в личку
  downloader.py    yt-dlp: TikTok без водяного знака, YouTube, VK
  animations.py    кадры .love
  texts.py         все тексты бота
  handlers/
    business.py    команды, мут, антимут + сторож удалений, одноразовые
    edits.py       уведомления о правках
    connection.py  подключение/отключение и права
    private.py     /start, /status, настройки, ссылки в личке
tests/             фейковый Telegram API + сквозные сценарии
```

```bash
pip install -r requirements-dev.txt
pytest
```
