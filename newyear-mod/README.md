# 1DEX1 New Year — новогодний мод для Minecraft 1.21.11 (Fabric)

Только визуальные эффекты и только на твоём клиенте. На сервер ничего не ставится, другие игроки эффекты не видят.

Готовый файл: [`release/1DEX1-New-Year-1.3.0.jar`](release/1DEX1-New-Year-1.3.0.jar)

> В моде **нет чужих песен**: распространять их без разрешения правообладателей нельзя. Свои песни игрок кладёт в папку `.minecraft/1dex1-music` (см. «Музыка»).

## Установка
1. Fabric Loader для Minecraft **1.21.11**.
2. Положи `1DEX1-New-Year-1.3.0.jar` в `.minecraft/mods`. Fabric API не нужен, нужное уже внутри.
3. Меню открывается на **F8** — и в игре, и в главном меню. Клавишу можно сменить: Настройки → Управление → Назначения клавиш → «Новый год (1DEX1)».
4. Если вместе стоит 1DEX1 PvP AI, у него тоже F8: поменяй клавишу одному из модов, иначе по F8 откроется только одно меню.

## Главное меню
Вместо панорамы — уютная новогодняя картинка с камином. Она рисуется самим модом, поэтому её не перекрывает ресурспак. Камин чуть «дышит» тёплым светом. Выключается в «Визуал → Новогодний фон».

## Меню (F8)
Колонки по категориям, компактные строки без иконок и без поясняющих надписей. **ЛКМ** — включить/выключить, **ПКМ** — раскрыть настройки под строкой (у функций без настроек ПКМ ничего не делает).
Текст рисуется собственным рендером шрифта Inter со сглаживанием, как в современных лаунчерах: он не дрожит при анимациях меню.

### Снег
| Функция | Что делает | Настройки |
|---|---|---|
| **Снегопад** | Снежинки в мире вокруг тебя. Под крышей снега нет | Сила 1–10, размер снежинок, ветер |
| **Сугробы** | Снежный покров с большими сугробами у стен и деревьев. Снег лежит и **на крышах, полублоках и кронах деревьев**, а в снежных биомах ложится поверх ванильного снега без мерцания. Хрустящий звук шагов | Размер, крыши и деревья, звук шагов, громкость |
| **Следы на снегу** | За тобой и другими игроками остаются следы, их постепенно заметает | — |
| **Снег на игроках** | Если стоять под снегопадом, на голове и плечах копится снег (поверх брони тоже). Если побежать или прыгнуть — стряхивается | — |
| **Снег на экране** | Снег поверх интерфейса копится сугробами на чате, хотбаре, кнопках и окнах | Количество, сугробы, поверх игры |
| **Снежки и снеговик** | Клик по снегу — снежок, тащи по снегу — растёт. **Отпусти аккуратно** — снежок встанет на снег (на чате, кнопках, меню) или на другой снежок. **Брось резко** — разлетится при ударе. 3 снежка друг на друга — снеговик (5 видов), гуляет 20 секунд и рассыпается в горку. Брошенный снежок сбивает снеговика. Резкий взмах мышкой разбрасывает снег | — |
| **Рудольф** | Нарисованный оленёнок с красным светящимся носом и колокольчиком скачет галопом внизу экрана и поднимает снег | — |

### Зима
| Функция | Что делает |
|---|---|
| **Шапки** | Шапка Санты на всех игроках |
| **Гирлянды** | Мигающая гирлянда над ником |
| **Украшения на ёлках** | Шарики и светящиеся огоньки на деревьях вокруг (на елях гуще) |
| **Сосульки** | Свисают с краёв крыш, с них иногда капает |
| **Лёд на воде** | Тонкий лёд у берегов |
| **Зимний фильтр** | Снежная трава и листва, холодный оттенок, иней по краям |
| **Пар изо рта** | Облачка пара у игроков рядом |
| **Звёздное небо** | Ночью звёзды ярче |

### Музыка
| Функция | Что делает |
|---|---|
| **Музыка** | Плеер: название, исполнитель, прогресс, живой эквалайзер, кнопки «Назад / Пауза / Далее», громкость, порядок (подряд / повтор / случайно). Пока играет новогодняя музыка, ванильная молчит |
| **Песни** | Список всех песен, клик — включить. Кнопки «Открыть» (папка `.minecraft/1dex1-music`) и «Обновить» |
| **Снег под бит** | На каждый бит — порыв ветра и волна снежинок (в мире и на экране) |
| **Ускорение снега** | Чем громче песня, тем быстрее и гуще идёт снег |
| **Гирлянды под бит** | Гирлянды, огоньки на ёлках и на меню мигают в ритм |

Музыка работает и в главном меню, и в игре. Песни: положи `.ogg` или `.mp3` в `.minecraft/1dex1-music` (кнопка «Папка») и нажми «Обновить». Название берётся из имени файла `Исполнитель - Песня.mp3`.

### Визуал
Фон меню, обычный или стекло, гирлянда на меню, цвет пипеткой, новогодний фон главного меню.

Настройки сохраняются в `.minecraft/config/1dex1-newyear.json`.

## Совместимость
- Снежная трава и листва, яркость звёзд могут не работать с шейдерами (Iris).
- Сугробы, следы, сосульки и лёд — только визуал: на сервере их нет, ты проходишь сквозь них.

## Сборка
```
./gradlew build            # с песнями из music-local/ (если папка есть)
./gradlew build -PnoSongs  # без песен
```
