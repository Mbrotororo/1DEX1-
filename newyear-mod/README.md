# 1DEX1 New Year — новогодний мод для Minecraft 1.21.11 (Fabric)

Только визуальные эффекты и только на твоём клиенте. На сервер ничего не ставится, другие игроки эффекты не видят.

Готовый файл: [`release/1DEX1-New-Year-1.0.0.jar`](release/1DEX1-New-Year-1.0.0.jar)

## Установка
1. Fabric Loader для Minecraft **1.21.11**.
2. Положи `1DEX1-New-Year-1.0.0.jar` в `.minecraft/mods`. Fabric API не нужен, нужное уже внутри.
3. Меню открывается на **F9**. Клавишу можно сменить: Настройки → Управление → Назначения клавиш → «Новый год (1DEX1)».
4. Работает вместе с 1DEX1 PvP AI (там F8).

## Меню (F9)
Стеклянное меню в стиле 1DEX1 с гирляндой по верхнему краю. 8 плиток: **ЛКМ** — включить или выключить, **ПКМ** (или «•••») — настройки.

| Функция | Что делает | Настройки |
|---|---|---|
| **Снегопад** | Снежинки падают в мире вокруг тебя в любом биоме. Под крышей снега нет | Сила 1–10 (до метели), снежинки мелкие / разные / крупные, ветер |
| **Снег на экране** | Снег падает поверх интерфейса: в игре, в чате, в меню, в инвентаре. Снег **копится сугробами** на чате, строке ввода, хотбаре, кнопках, окнах инвентаря и на самом меню, а когда окно закрывается, тает | Количество, сугробы вкл/выкл, снег поверх игры вкл/выкл |
| **Шапки** | Шапка Санты на всех игроках, на тебе тоже (от третьего лица и в инвентаре). Если на голове шлем, шапка надевается поверх него | На мне, на других |
| **Гирлянды** | Мигающая разноцветная гирлянда над ником каждого игрока | Скорость мигания |
| **Зимний фильтр** | Трава и листва становятся снежными, холодный оттенок, иней по краям экрана | Снежная трава, иней, сила оттенка |
| **Пар изо рта** | Облачка пара у игроков рядом. Когда бегут — чаще | — |
| **Звёздное небо** | Ночью звёзды намного ярче | Яркость |
| **Визуал** | Внешний вид меню | Фон белый / серый / чёрный, обычный или стекло, гирлянда на меню, цвет пипеткой |

Настройки сохраняются в `.minecraft/config/1dex1-newyear.json`.

## Совместимость
- Снежная трава и листва может не работать с шейдерами (Iris) и некоторыми ресурспаками, её можно выключить отдельно.
- С шейдерами яркость звёзд может не меняться.
