# 1DEX1 New Year — новогодний мод для Minecraft 1.21.11 (Fabric)

Только визуальные эффекты и только на твоём клиенте. На сервер ничего не ставится, другие игроки эффекты не видят.

Готовый файл: [`release/1DEX1-New-Year-1.1.0.jar`](release/1DEX1-New-Year-1.1.0.jar)

## Установка
1. Fabric Loader для Minecraft **1.21.11**.
2. Положи `1DEX1-New-Year-1.1.0.jar` в `.minecraft/mods`. Fabric API не нужен, нужное уже внутри.
3. Меню открывается на **F8**. Клавишу можно сменить: Настройки → Управление → Назначения клавиш → «Новый год (1DEX1)».
4. Если вместе стоит 1DEX1 PvP AI, у него тоже F8: поменяй клавишу одному из модов, иначе по F8 откроется только одно меню.

## Меню (F8)
Колонки по категориям, в каждой компактный список функций без иконок, как в клиентах.
**ЛКМ** по строке — включить или выключить, **ПКМ** — раскрыть настройки прямо под строкой.

### Снег
| Функция | Что делает | Настройки |
|---|---|---|
| **Снегопад** | Снежинки падают в мире вокруг тебя в любом биоме. Под крышей снега нет | Сила 1–10 (до метели), мелкие / разные / крупные, ветер |
| **Сугробы** | Мягкий снежный покров на земле вокруг тебя: большие сугробы у стен, домов и деревьев, отдельные снежные горки. Когда идёшь по ним — хрустящий звук шагов | Размер: малые / средние / огромные, звук шагов, громкость |
| **Снег на экране** | Снег падает поверх интерфейса и копится сугробами на чате, хотбаре, кнопках, окнах и на меню. Когда окно закрывается, снег тает | Количество, сугробы, снег поверх игры |
| **Снежки и снеговик** | Кликни по снегу на экране — получится снежок. Тащи его по снегу — он растёт. Поставь 3 снежка друг на друга — появится маленький снеговик, он гуляет 20 секунд и рассыпается в горку снега. Резко проведи мышкой по сугробу — снег разлетится | — |

### Атмосфера
| Функция | Что делает | Настройки |
|---|---|---|
| **Шапки** | Шапка Санты на всех игроках (на тебе — от третьего лица и в инвентаре), поверх шлема тоже | На мне, на других |
| **Гирлянды** | Мигающая гирлянда над ником каждого игрока | Скорость мигания |
| **Зимний фильтр** | Снежная трава и листва, холодный оттенок, иней по краям экрана | Снежная трава, иней, холод |
| **Пар изо рта** | Облачка пара у игроков рядом | — |
| **Звёздное небо** | Ночью звёзды намного ярче | Яркость |

### Визуал
Фон меню белый / серый / чёрный, обычный или стекло, гирлянда на меню, цвет пипеткой.

Всё работает только у тебя на клиенте: сугробы, шапки и снег видишь только ты, по сугробам ты проходишь насквозь (на сервере их нет).

Настройки сохраняются в `.minecraft/config/1dex1-newyear.json`.

## Совместимость
- Снежная трава и листва может не работать с шейдерами (Iris) и некоторыми ресурспаками, её можно выключить отдельно.
- Звук шагов: файл из присланного 1DEX1 звука, порезан на два шага.
- С шейдерами яркость звёзд может не меняться.
