# Один день из жизни Zako

Вертикальный ролик для TikTok канала **1DEX1**: 1080×1920, 30 fps, около 65 секунд.
Сделан на [Remotion](https://www.remotion.dev/) + three.js. Персонажи — настоящие 3D-модели
Minecraft со скинами Zako и 1DEX1, мир из блоков нарисован кодом.

Готово: сцены 1–2 (титульник и спальня). Остальные сцены пока заглушки «в работе».

## Запуск

Нужны Node.js 18+ и (только для переозвучки) Python 3.

```bash
cd zako-day-video
npm install
npm run dev      # предпросмотр в браузере (Remotion Studio)
npm run render   # готовое видео: out/zako-day.mp4
```

Звуки Minecraft скачиваются с серверов Mojang в `public/sounds/` перед запуском
(`scripts/fetch-sounds.mjs`), в репозитории их нет.

### Озвучка

Голос — нейросеть [Piper](https://github.com/rhasspy/piper) (`ru_RU-denis-medium`), работает офлайн.
После правки текста в `src/script.json`:

```bash
pip install piper-tts faster-whisper
npm run voice
```

Это перезапишет `public/voice/*.wav`, длительности (`src/voice.json`) и тайминги слов для
субтитров (`src/words.json`). Таймлайн сцен перестроится сам. Ударение в поле `tts` ставится
знаком ударения после гласной: `За́ко`.

Чтобы озвучить своим голосом: положи свои записи в `public/voice/<id>.wav` с теми же именами
и запусти `python3 scripts/align.py` — он пересчитает длительности и тайминги субтитров.

## Что где менять

| Что | Где |
| --- | --- |
| Текст, субтитры, озвучка | `src/script.json`, затем `npm run voice` |
| Паузы между сценами | `src/lib/timeline.ts` |
| Сцены | `src/scenes/*.tsx`, список сцен — `src/Video.tsx` |
| Скины | `public/skins/zako.png`, `public/skins/1dex1.png` |
| Эмоции (пиксели лица) | `src/lib/faces.ts` |
| Позы и движения | `src/lib/poses.ts` |
| Текстуры блоков | `src/lib/blocks.ts`, `src/lib/textures.ts` |
| Стиль субтитров | `src/ui/Subtitles.tsx` |
