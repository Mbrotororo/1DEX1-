# Письмо с QR-сердечком

Мини-открытка: она сканирует QR-код в форме сердца, попадает на страницу
«Эта эмоция закрыта словом», вводит слово-ответ, и ей приходит письмо в конверте с печатью.

| Файл | Что это |
| --- | --- |
| `index.html` | Страница, которую она откроет: замок со словом → «…, тебе письмо» → конверт → письмо |
| `card.html` | Генератор картинки с QR-сердцем (имя, цвет, узор, кнопка «Скачать PNG») |
| `qr-card.png` | Готовая картинка-открытка для ссылки `https://mbrotororo.github.io/1DEX1-/love/` |
| `heart-qr.js` | Рисует QR-код в форме сердца |
| `vendor/qrcode.js` | Библиотека QR-кодов (qrcode-generator, MIT) |
| `fonts/`, `fonts.css` | Шрифты Marck Script и Cormorant Garamond (SIL OFL) |

## Как подписать под себя

Открой `index.html` и поменяй блок `CONFIG` в самом верху:

- `name`: её имя (будет «Имя, тебе письмо» и надпись на конверте)
- `hint`: подсказка под замком, например «твои любимые цветы»
- `answers`: слова, которые откроют письмо (большие и маленькие буквы и «ё» не важны)
- `greeting`, `letter`, `signature`: само письмо, каждая строка в кавычках будет отдельным абзацем
- `photo`, `music`: по желанию положи `photo.jpg` или `song.mp3` в эту папку и впиши имя файла

После трёх неверных попыток страница сама подсказывает первую букву.

## Как выложить, чтобы QR работал

1. Влей эту ветку в `main`.
2. На GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.
3. Через минуту страница будет по адресу `https://mbrotororo.github.io/1DEX1-/love/`.
   На эту ссылку уже ведёт `qr-card.png`.

## Как сделать картинку с QR

Открой `https://mbrotororo.github.io/1DEX1-/love/card.html`, впиши её имя, выбери цвет и нажми «Скачать PNG».
Если письмо лежит на другом адресе, поменяй ссылку в поле «Ссылка в QR-коде».
