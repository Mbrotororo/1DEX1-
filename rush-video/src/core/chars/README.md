# Персонаж: мимика, слот на спине, позы ролика

Дополнение к `CORE_API.md` §9. Всё ниже обратно совместимо: старые пропсы `Humanoid` и старые позы работают
как раньше; новое включается только новыми пропсами/полями.

Галерея: `npm run shots -- --scene=rig --sheet --step=0.5` (сцена `src/scenes/_rig`, вне ролика):
0–6.6 — лицо экстремально крупно (все выражения, моргания, взгляд), 6.6–9 — средний план,
9–21 — четыре страницы новых поз (подписи под каждой), 21–29 — прыжок в кресло → печатает → кнопка ПК →
наушники → машет в камеру.

Импорт — из `src/core` (`import {Humanoid, mixFace, tiredWalk, ...} from '../../core'`).

---

## 1. Мимика — проп `face`

```tsx
<Player skin={assets.skin} position={pos} pose={pose} face={{tired: 1, blink: autoBlink(t, 1)}} />
```

`face?: Partial<FaceState>` — веса 0..1, их можно смешивать. Не задан — лицо как в скине (старое поведение).

| поле | что делает |
|---|---|
| `tired` | тяжёлые полуопущенные веки цвета кожи (глаза — тонкие тёмные щёлки), внешние уголки ниже, мешки под глазами (от ~0.25) |
| `shock` | от 0.3: глаза — белые вытянутые прямоугольники (~2.75×1.75 px скина) с маленькими зрачками, залезают под чёлку (в чёлке прорезаются «окна»), рот «О» открывается сам; белки слегка светятся, поэтому остаются белыми в тёплом тёмном свете |
| `focus` | решимость: прищур, внутренние уголки ниже (глаза «углом»), рот — короткая черта |
| `joy` | от 0.5: глаза «^^», улыбка, румянец; с `mouth ≥ 0.3` — открытая улыбка с зубами |
| `blink` | 1 — глаза закрыты (веко опускается до конца; работает поверх любого выражения, кроме «^^») |
| `mouth` | открытый рот 0..1 (вздох, крик); при `shock` открывается сам |
| `lookX`, `lookY` | взгляд −1..1: `lookX > 0` — к левому плечу героя (+x персонажа), `lookY > 0` — вверх. Тёмный глаз сдвигается целиком (до ~0.75 px скина), у белого глаза бегает зрачок |

Как устроено (`face.ts`): передняя грань головы получает свою текстуру 32×32 — лицо скина, увеличенное в 4 раза
без сглаживания, плюс пиксельные накладки с шагом ¼ пикселя скина. Остальные грани головы, чёлка (второй слой
`hat`, раздут на 0.5 px — z-fighting нет) и всё тело рисуются как раньше. Раскладка лица — под скин 1DEX1
(глаза в строке 5: x = 1,2 и 5,6 под чёлкой, светлая строка 6, рот — строка 7).

Производительность: состояние квантуется до субпикселей (переход 0→1 даёт ~5–10 разных картинок), текстуры
кэшируются (LRU на 48 штук на все скины, лишние освобождаются), материалы свои у каждого `Humanoid` и не
пересоздаются. Кадр 1920×1080 с лицом на весь экран — ~240 мс (`--bench`).

Ограничения: мимика только у несветящихся скинов (у `griefer` — нет); только передняя грань (в профиль лицо
видно с боковой грани как в скине); при `hurt`/`frozen` > 0 свечение белков выключается.

### Помощники

```ts
mixFace(a, b, k)                    // смешать два выражения: k 0 → a, 1 → b
blinkAt(t, at, dur = 0.16)          // одно моргание: 0 → 1 → 0, закрывается быстрее, чем открывается
autoBlink(t, seed = 1, period = 3.2, dur = 0.16)   // моргает сам примерно раз в period с (детерминированно)
FACE_NEUTRAL                        // все нули
faceTextures(skin, face)            // текстуры выражения (нужно редко — Humanoid вызывает сам)
```

Примеры:

```ts
// A2: устал, медленное моргание (dur 0.4) и выдох ртом
face={{tired: 1, blink: Math.max(autoBlink(t, 2, 2.4, 0.3), blinkAt(t, BEATS.slowBlink, 0.45)), mouth: 0.4 * pulse(t, 4.6, 5.3, 0.15, 0.4)}}
// A5: шок с ударом (за 2–3 кадра) и бегающими зрачками
face={{...mixFace({tired: 1}, {shock: 1}, smooth(prog(t, BEATS.shock, 0.05))), lookX: noise1(t * 6, 3) * 0.4}}
// A6–A8: решимость
face={{focus: 1, blink: autoBlink(t, 4, 2.5)}}
// B7: радость
face={{joy: 1, mouth: 0.6, blink: autoBlink(t, 5)}}
```

Крупный план лица: камера ~1.2 блока от центра головы, fov 30 — лицо на весь кадр. Строка глаз (5-я строка
скина) — на высоте `position.y + 1.55` (стоя), центр головы — `headAnchor(pose)`.

## 2. Слот на спине — проп `backSlot`

```tsx
<Player ... backSlot={<Backpack />} />
```

- Начало координат — **центр задней поверхности туловища** (по второму слою, куртке): по центру по ширине и по
  высоте туловища, на 2.26 px скина (0.132 блока) за осью тела.
- Оси — персонажа: `x` — к левому плечу, `y` — вверх, `z` — вперёд. Рюкзак строится в сторону **−z**
  (то, что «на спине», имеет z < 0). Единицы — блоки.
- Двигается с корпусом: `lean`, `tumble`, `squash`, `scale`, `rotationY` пропсов и `bend/twist/tilt/shrug/dy/lean` позы.
  Ноги на него не влияют.
- Туловище 8×12 px = 0.47 × 0.70 блока: рюкзак шириной ~0.44 и высотой ~0.5 блока сидит ровно.
- Где эта точка в мире (например, чтобы рюкзак «слетел» со спины в этот момент): `worldPoint(backAnchor(pose), position, rotationY)`.

## 3. Точки скелета — `anchors.ts` (чистый модуль)

```ts
handAnchor(pose, 'R' | 'L', build = 'slim')  // «кулак» (куда крепится handR/handL)
backAnchor(pose)                             // начало backSlot
headAnchor(pose)                             // центр головы (начало headSlot)
worldPoint(local, position, rotationY = 0, scale = 1)   // из координат персонажа в мир
```

Возвращают `Vec3` в координатах персонажа (относительно `position`, до поворота). Учитывают `dy, lean, bend, twist,
tilt, shrug` позы; `lean/tumble/squash` пропсов — нет. Применение: момент выпуска брошенной шапки/рюкзака,
кнопка ПК, куда дотягивается рука, точка для частиц.

```ts
// шапка вылетает из руки в момент выпуска и дальше летит по своей формуле
const p0 = worldPoint(handAnchor(flingHat(0.6), 'R'), pos, yaw);
```

## 4. Новые поля позы

Все необязательные (старые позы их не задают = 0), `mixPose` их смешивает.

| поле | смысл |
|---|---|
| `bend` | наклон корпуса (голова, туловище, руки, backSlot) вперёд вокруг бёдер, рад; ноги остаются на месте (сутулится). Отличие от `lean`: `lean` наклоняет всё тело вокруг ступней |
| `twist` | поворот корпуса вокруг вертикали над бёдрами, рад; > 0 — влево (к +x персонажа) |
| `tilt` | наклон корпуса вбок, рад; > 0 — вправо (к −x персонажа) |
| `shrug` | плечи вверх (> 0) / вниз (< 0), пиксели скина (1 px = 0.059 блока): вдох, «опущенные плечи» |

`mirrorPose(p)` — зеркальная поза (правое ↔ левое): например, бросок левой рукой.

---

## 5. Новые позы

Все — чистые функции, возвращают обычный `Pose`. Обозначения: `k` — прогресс действия 0..1
(`prog(t, start, dur)`), `t` — время, `phase` — фаза шага (из `makePath().at(t).phase` или `t * N`).
Позы-действия начинаются и заканчиваются в «нейтрали» (близко к `POSE_ZERO`/`sit()`), их удобно включать через
`mixPose(base, action(k), k > 0 && k < 1 ? 1 : 0)` или через `smooth`-окно.

### Усталость

| поза | аргументы и тайминг |
|---|---|
| `tiredWalk(phase, amount = 1)` | плетётся: ссутулился (`bend` 0.26), голова опущена, плечи вниз, руки висят и почти не качаются, шаг короткий. `makePath(keys, {stride: 0.6})` или `phase = t * 5`. `dy` держит ступни на полу |
| `slump(t)` | стоит уставший: плечи опущены, тяжело дышит (цикл ~2.6 с), голова вниз |
| `sigh(k)` | тяжёлый вздох поверх slump: 0..0.4 — вдох (плечи и голова вверх, корпус выпрямляется), 0.5..0.8 — выдох (обмяк), к 1 — снова slump. Длительность 1.4–2 с. `mixPose(slump(t), sigh(k), smooth(k * 8))`. Пар/рот: `face.mouth` на выдохе |
| `lookUp(k, pitch = -0.32)` | от сутулого slump к «выпрямился и смотрит вверх на стену»: голова опережает корпус (голова — 0..0.7, корпус — 0.15..1). `pitch` — итоговый наклон головы (отрицательный — вверх). 0.8–1.2 с |

### Шок и броски

| поза | аргументы и тайминг |
|---|---|
| `shockPose(k)` | рывок: откидывается назад, руки вскинуты вверх-в стороны, голова запрокинута, плечи вверх. Удар — первые 12 % k (с перелётом), дальше дрожь затухает и он чуть обмякает. k на весь испуг 1.2–1.6 с; включать за 0.05–0.08 с |
| `flingHat(k)` | правая рука срывает шапку и швыряет вперёд-вправо. 0..0.22 — рука к макушке (схватил ~0.22), 0.22..0.4 — поднял над головой, 0.4..0.5 — замах в сторону, **выпуск ~0.6**, 0.72..1 — рука опускается. Шапка: `headSlot` до 0.22 → `handR` 0.22..0.6 → дальше летит сама из `handAnchor(flingHat(0.6), 'R')`. Длительность ~0.8 с |
| `hurlBackpack(k)` | 0..0.12 — дёрнул плечами, 0.08..0.3 — стряхивает лямки (правая рука ловит лямку за спиной ~0.3), 0.35..0.6 — размах сбоку с разворотом корпуса, **выпуск ~0.6**, 0.6..0.8 — доводка через корпус, к 1 — выпрямился. Рюкзак: `backSlot` до ~0.3 → `handR` 0.3..0.6 → летит из `handAnchor(hurlBackpack(0.6), 'R')`. Длительность 1–1.2 с (выпуск — на долю) |

### Бег

| поза | аргументы и тайминг |
|---|---|
| `sprintStairs(phase, amount = 1)` | спринт вверх по лестнице: колени (ноги) выше вперёд, сильный наклон (`lean` 0.16 + `bend` 0.34), руки работают. `phase = t * 14` или из `makePath` (stride ≈ 1.6 по горизонтали). `y` героя ведёт сцена по ступеням |
| `doorShove(k, base = POSE_ZERO)` | на бегу распахивает дверь правой рукой: 0..0.3 — рука к груди, плечо назад, **удар ~0.42**, 0.55..1 — рука возвращается в base. `base` — поза бега (ноги, наклон берутся из неё): `doorShove(k, sprint(phase))`. Левой рукой: `mirrorPose(doorShove(k, mirrorPose(base)))`. 0.4–0.5 с, удар — на долю |

### Посадка и компьютер

**Сиденье.** Все сидячие позы совпадают с `sit()` по ногам и `dy = −0.59`: ставь героя `position.y = верх сиденья`,
`position.x/z` — центр сиденья (бёдра над точкой `position`, ноги вытянуты вперёд на ~0.7 блока, корпус над ней).
Стол: верх ≈ сиденье **+0.38..0.42**, передний край ≈ 0.3 перед героем. Кулаки при печати: правый ≈ (−0.33, +0.48, +0.55),
левый ≈ (+0.27, +0.54, +0.54) относительно `position` — клавиатура у переднего края стола.

| поза | аргументы и тайминг |
|---|---|
| `diveIntoChair(k)` | прыжок в кресло: 0..0.18 — толчок (корпус вперёд, руки назад), 0.16..0.72 — полёт (руки вперёд-вверх, ноги подтягиваются, `dy` уходит в −0.59), ~0.75 — плюхнулся (руки разлетаются, голова кивает), 0.8..1 — оседает и при k = 1 **ровно `sit()`**. 0.8–1 с |
| `diveArc(k, from, seat, height = 0.7)` | положение для diveIntoChair: стоит в `from` (пол) до k = 0.16, летит по дуге до 0.72, дальше — в `seat` (верх сиденья). Разворот к столу в полёте — сам: `yaw = lerp(yaw0, yaw1, smooth((k - 0.15) / 0.55))` |
| `sitIdle(t)` | сидит и дышит |
| `sitTyping(t, amount = 1)` | обе руки вперёд на клавиатуре, кисти мелко подрагивают (детерминированный шум), чуть наклонился к экрану |
| `sitMouse(t, clicks = [])` | правая рука на мыши (мышь ездит), левая — на клавиатуре; в каждый момент из `clicks` — «клик» (рука вздрагивает за 0.05 с до и 0.15 с после) |
| `sitReach(k, low = 1)` | тянется вперёд-вниз и жмёт кнопку правой рукой: 0..0.4 — тянется, **~0.5 — нажал**, 0.62..1 — вернулся в `sit()`. `low`: 1 — кнопка под краем стола (кулак ≈ (−0.36, +0.29, +0.58) от `position`), 0 — кнопка на корпусе, стоящем на столе (≈ (−0.36, +0.63, +0.59)). Точно: `handAnchor(sitReach(0.5, low), 'R')`. 0.8–1.1 с |
| `headphonesOn(k, base = sit())` | двумя руками поднимает наушники над головой (0..0.35), опускает на уши (0.35..0.7, **надел ~0.7**), руки возвращаются в `base` (0.72..1). Сами наушники — в `headSlot` со сдвигом `headphonesLift(k)`. 1–1.2 с |
| `headphonesLift(k)` | сдвиг наушников в `headSlot` (блоки от центра головы): перед лицом → над макушкой (0.35) → на голове (0.7, дальше `[0, 0, 0]`) |
| `sitCheer(t, turn = 0)` | сидя радуется, обе руки вверх. `turn` — поворот корпуса к камере (> 0 — влево), рад: корпус `twist = 0.7·turn`, голова ещё `0.3·turn` |
| `sitWave(t, turn = 0)` | сидя машет правой рукой в камеру; `turn` — как у sitCheer |

Пример — посадка (как в галерее):

```ts
const kd = prog(t, BEATS.dive, 1.0);
const pos = diveArc(kd, [1.45, FLOOR, -0.15], [0, FLOOR + SEAT, 0], 0.65);
const yaw = lerp(-Math.PI / 2, 0, smooth((kd - 0.15) / 0.55));
let pose = diveIntoChair(kd);
if (t > BEATS.typing) pose = mixPose(sit(), sitTyping(t), smooth((t - BEATS.typing) / 0.3));
// кнопка ПК (сиденье — position): кнопку ставим туда, куда дотягивается рука
const BUTTON = worldPoint(handAnchor(sitReach(0.5), 'R'), SEAT_POS, SEAT_YAW);
// наушники
const kp = prog(t, BEATS.phones, 1.2);
<Player ... pose={headphonesOn(kp, sitTyping(t))} headSlot={<group position={headphonesLift(kp)}><Headphones /></group>} />
```

Пример — прихожая:

```ts
// плетётся с рюкзаком
const st = path.at(t);   // makePath(keys, {stride: 0.6})
<Player position={st.position} rotationY={st.heading} pose={mixPose(slump(t), tiredWalk(st.phase), st.moving)}
        face={{tired: 1, blink: autoBlink(t, 2, 2.8, 0.3)}} backSlot={<Backpack />} />
// шок
const ks = prog(t, BEATS.shock - 0.05, 1.5);
pose = mixPose(lookUp(1), shockPose(ks), smooth(ks * 30));
```
