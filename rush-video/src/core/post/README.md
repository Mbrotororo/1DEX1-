# Постобработка («киношный» вид) и видоискатель камеры

Папка `src/core/post/` — глубина резкости, свечение, виньетка, зерно, цветокоррекция, вспышка, аберрация, смаз
«вжух». `src/core/hud/rec.tsx` — видоискатель камеры (`● REC`, тайм-код) для кадра B7.
Демо и проверка — служебная сцена `look` (`src/scenes/_look`): `npm run shots -- --scene=look --sheet`.

Всё экспортируется и из `src/core` (блок `// --- look` в `src/core/index.ts`), и из `src/core/post`.

---

## 1. Как включить в сцене

У `SceneDef` есть необязательное поле `post` — чистая функция времени, как камера:

```ts
import {POST, withFocus, type SceneDef} from '../../core';

export const scene: SceneDef = {
	id: 'a-home', camera, World, Overlay,
	// фокус на глазах героя, остальное — пресет
	post: (t, cam) => withFocus(POST.closeUp, cam, [hx, hy + 1.53, hz]),
};
```

- Нет поля `post` (или функция вернула `null`) — кадр рисуется **ровно как раньше** (старые сцены, стенды, галереи не меняются).
- `POST.none` (все эффекты нейтральны) — тоже рисуется напрямую, без конвейера: пиксель в пиксель как без постобработки.
- Глобально выключить для быстрых черновиков: входной параметр композиции `post: false`
  (`npx remotion render RushVideo out/x.mp4 --props='{"post":false}'`).
- `t` и `cam` — те же, что получают `World`/`Overlay` (локальное время сцены и камера кадра).

## 2. Настройки `PostSettings`

Размеры в пикселях даются **для кадра 1080p** (при 960×540 конвейер сам делит пополам). Расстояния — в блоках.

| поле | смысл | нейтрально | обычно |
|---|---|---|---|
| `focus` | расстояние до плоскости фокуса по оси взгляда камеры, блоки (см. `withFocus`, `focusDist`) | 6 | крупный план 1–2, средний 3–5 |
| `dof` | размытие на бесконечности, пиксели (0 — выкл.) | 0 | 6 мягко, 12–18 сильно, 20–24 максимум |
| `focusRange` | ширина зоны полной резкости вокруг фокуса, блоки | 1 | 0.4–0.6 крупно, 2–4 общий |
| `nearBlur` | размытие переднего плана относительно фона (0 — передний план всегда резкий) | 1 | 0.8–1 |
| `bloom` | сила свечения ярких мест (0 — выкл.) | 0 | 0.5–1 |
| `bloomThreshold` | порог яркости (линейная, 0..1): светится то, что ярче | 0.8 | 0.5–0.75 в тёмных интерьерах |
| `bloomRadius` | ширина ореола 0..1 | 0.6 | 0.5–0.8 |
| `vignette`, `vignetteSoft` | затемнение краёв 0..1 и мягкость 0..1 | 0, 0.6 | 0.3–0.5, 0.7 |
| `grain` | плёночное зерно 0..1 (детерминированное: зерно = функция номера кадра) | 0 | 0.2–0.35 |
| `chroma` | хроматическая аберрация у краёв кадра, пиксели | 0 | 1–3 |
| `smear`, `smearAngle` | смаз движения: длина, пиксели; направление, радианы (0 — горизонталь) | 0, 0 | 40–90 на «вжух» (см. `whipSmear`) |
| `exposure` | экспозиция, ступени (+1 — вдвое ярче) | 0 | −0.2…+0.2 |
| `contrast`, `saturation` | контраст и насыщенность (1 — как есть) | 1, 1 | 1.05–1.3, 0.8–1.2 |
| `warmth`, `tint` | баланс белого: тепло (+)/холод (−) −1..1; пурпур (+)/зелень (−) | 0, 0 | ±0.3 |
| `split` | «тил-оранж»: тени в бирюзу, света в оранжевый, 0..1 | 0 | 0.2–0.4 |
| `lift`, `gamma`, `gain` | подъём теней, гамма средних (>1 светлее), усиление светов | 0, 1, 1 | ±0.02, 1–1.05, 1–1.05 |
| `flash`, `flashColor` | заливка цветом поверх 3D 0..1 (склейки, шок) | 0, `#ffffff` | `impulse(t, at, 22)` — 2–3 кадра |

Собрать свои: `post({...})` (нейтральные + переопределения) или `{...POST.warmInterior, dof: 12}`.

## 3. Пресеты `POST`

| имя | для чего |
|---|---|
| `POST.none` | ничего (кадр как без постобработки) |
| `POST.warmInterior` | тёплый тёмный интерьер, общий/средний план: лёгкая глубина резкости (dof 6), свечение фонарей, виньетка, зерно, тепло + тил-оранж |
| `POST.closeUp` | крупный план: сильно размытый фон (dof 18, зона 0.5), мягкое свечение, плотная виньетка, лёгкая аберрация |
| `POST.screenPOV` | экран ПК во весь кадр: без размытия, свечение экрана, холоднее, аберрация 1.6 |
| `POST.coldDay` | холодный дневной свет (улица в проёме двери) |
| `POST.shock` | шок: жёсткий контраст, холоднее, ненасыщенно, сильная виньетка, dof 20, аберрация 3 (вспышку добавляет сцена) |
| `POST.happy` | радостный финал: теплее, ярче, насыщеннее |

Глубина резкости у всех пресетов — на `focus` по умолчанию; фокус почти всегда ставится от точки: `withFocus(...)`.

## 4. Помощники

| функция | что делает |
|---|---|
| `post(over)` | нейтральные настройки + переопределения |
| `mixPost(a, b, k)` | смесь двух наборов (k 0..1); фокус смешивается в обратных расстояниях — перевод фокуса как у объектива |
| `postTrack(t, [[t0, A], [t1, B], ...])` | настройки по ключам времени с плавными переходами (smoothstep) |
| `withFocus(s, cam, p)` | те же настройки с фокусом на точке мира `p` |
| `focusDist(cam, p)` | расстояние от камеры до точки по оси взгляда (то, что кладётся в `focus`) |
| `rackFocus(cam, from, to, k)` | перевод фокуса между двумя точками (k 0..1), возвращает `focus` |
| `cocAt(s, z)` | размытие (пиксели 1080p) у точки на расстоянии `z` — подбирать `dof`/`focusRange` |
| `whipSmear(dAngle, fov, shutter = 0.5)` | длина смаза (пиксели) для поворота камеры на `dAngle` радиан за кадр |
| `postIsNeutral(s)` | настройки ничего не меняют (кадр пойдёт напрямую) |

### Примеры

```ts
// крупный план лица (A2): фокус на глазах, фон сильно размыт
post: (t, cam) => withFocus(POST.closeUp, cam, eyes(t)),

// перевод фокуса с героя на часы (A2 -> A3): 0.6 с начиная с 5.2
post: (t, cam) => ({...POST.closeUp, focus: rackFocus(cam, eyes(t), CLOCK, smooth(prog(t, 5.2, 0.6)))}),

// шок (A5): пресет плавно за 0.12 с + белая вспышка 2–3 кадра на 8.0
post: (t, cam) => {
	const s = mixPost(POST.closeUp, POST.shock, smooth(prog(t, 8.0, 0.12)));
	return {...withFocus(s, cam, eyes(t)), flash: impulse(t, 8.0, 22)};
},

// смена настроения по ходу сцены
post: (t, cam) => withFocus(postTrack(t, [[0, POST.coldDay], [3.6, POST.warmInterior], [8, POST.shock]]), cam, HEAD),

// «вжух»-панорама: длина смаза от угловой скорости камеры (yaw(t) — угол поворота камеры, радианы)
post: (t, cam) => {
	const sm = whipSmear(yaw(t + 1 / 120) - yaw(t - 1 / 120), cam.fov);
	return {...POST.warmInterior, smear: sm, chroma: Math.min(3, sm / 30)};
},
```

## 5. Как устроено

Один конвейер на рендерер (на вкладку), внутри общего `ThreeCanvas` (`PostFX` в `player.tsx`). `PostFX` берёт
отрисовку на себя (`useFrame` с приоритетом 1 — R3F тогда сам не рисует): один кадр Remotion = один проход.
Анимации внутри нет: настройки и время приходят пропсами.

1. Мир → 8-битный буфер + текстура глубины, **без MSAA** (в программном WebGL MSAA-буфер стоит ~350 мс на 1080p);
   края сглаживает FXAA в финальном проходе. Цвет в буфере уже в sRGB, как на экране (буфер помечен как XR-буфер
   three: шейдеры кодируют выход в sRGB): прозрачное (свечения `Glow`, тени, частицы) смешивается в тех же числах,
   что и без постобработки.
2. Глубина резкости — на половинном разрешении: уменьшение с выбором дальнего из 2×2 (фон за силуэтом без примеси
   героя), плитки максимума размытия переднего плана (8×8) + расширение, сбор 18 образцов по повёрнутой золотой
   спирали с учётом перекрытия. Сведение в полный размер — с учётом глубины (без каймы вокруг резкого героя).
3. Свечение — от четверти разрешения: выделение ярких с мягким коленом, 6 уровней уменьшения/увеличения.
4. Финал (полный размер, один проход): FXAA, смешивание с размытым, свечение, экспозиция и баланс белого
   (линейно), sRGB, контраст, lift/gain, гамма, насыщенность, тил-оранж, виньетка, аберрация/смаз, зерно, вспышка.
   Каждая часть включается `#define` только когда нужна.
5. Экранный 3D-слой (`HudLayer`: `VoxelText`, `ExtrudedLogo`) рисуется **после** постобработки — резко, без
   размытия, цвета, зерна и вспышки. DOM-слой `Overlay` поверх всего, постобработка его не трогает.
   Вспышка `flash` заливает только 3D-мир; заливку всего кадра (вместе с надписями) делает `Fade` в `Overlay`.

### Проверено

- **Детерминизм:** кадры 60, 510, 1155 сцены `look` (глубина резкости, свечение, аберрация, зерно, вспышка, смаз)
  в отдельных вкладках и в одной вкладке вперемешку с другими кадрами — 0 различающихся пикселей.
- **Нейтральность:** `POST.none` против `post: false` — 0 различающихся пикселей (кадр идёт напрямую).
  Нейтральные настройки, но через конвейер (`vignette: 0.0011`): средний сдвиг цвета 0.01/255, различия только
  на рёбрах (FXAA вместо MSAA), цвет и смешивание прозрачного совпадают.
- **Края:** у резкого героя на сильно размытом фоне нет ореола и «призрачного» контура (`--full`, увеличение 2×).

### Стоимость (1920×1080, одна вкладка, `look`: комната + герой; кадр без постобработки ~220–240 мс)

| настройки | прибавка к кадру |
|---|---|
| `POST.none` | 0 (кадр напрямую) |
| нейтрально через конвейер (только FXAA) | ~+30 мс |
| только цвет/виньетка/зерно | ~+25 мс |
| `POST.warmInterior` (dof 6 + свечение + цвет + зерно) | ~+200–230 мс |
| `POST.closeUp` (dof 18 + свечение + аберрация + ...) | ~+200 мс |
| `POST.shock` (dof 20 + аберрация 3 + свечение 1) — самый дорогой | ~+340–460 мс |
| `warmInterior` + смаз «вжух» 70 px + аберрация | ~+320 мс |

Цена почти не зависит от сцены (считается по пикселям), поэтому в тяжёлом интерьере прибавка та же. Самое дорогое —
сбор глубины резкости (~10 мс на образец спирали, 18 образцов); без `dof` конвейер стоит ~+30–130 мс; аберрация
~+30–100 мс (на шоке её можно взять 1.5). Замеры сделаны, пока на тех же 4 ядрах рендерили другие, и плавают на ±30%.

### Ограничения

- При включённой постобработке края сглаживает FXAA, а не MSAA: рёбра чуть мягче, текстуры чуть менее «звонкие».
  На стыке `POST.none` → любой пресет сглаживание меняется (на глаз незаметно).
- Размытый передний план растекается на резкий фон примерно на половину своего радиуса (частичное перекрытие
  приближённое).
- Свечение берётся из 8-битного кадра: яркость источников ограничена 1.0, «пересвет» не накапливается —
  силу задаёт `bloom`.
- Смаз «вжух» — одно направление на весь кадр (поворот камеры), не по объектам.

## 6. Видоискатель камеры — `Viewfinder` (`src/core/hud/rec.tsx`)

DOM-слой (кладётся в `Overlay`), как в примере пользователя: тонкие перекрестья в углах (линии уходят за край кадра),
маленькое перекрестье в центре, `● REC` слева сверху (красная точка мигает), бегущий тайм-код справа сверху
`00:00:00.000`, `1080p  60fps` слева снизу. Шрифт — Inter (`public/fonts/inter-*`), лёгкое начертание 400 с тенью;
кадр не снимается, пока шрифт не загружен (`delayRender`).

```tsx
import {Viewfinder} from '../../core';

const Overlay: React.FC<SceneProps> = ({t}) => (
	<Viewfinder t={t} start={10.4} opacity={smooth(prog(t, 10.4, 0.15))} />
);
```

| проп | смысл | по умолчанию |
|---|---|---|
| `t` | время сцены, секунды | — |
| `start` | момент начала записи: тайм-код = `t − start` (до него — нули) | 0 |
| `opacity` | общая прозрачность 0..1 | 1 |
| `label` | подпись слева снизу | `'1080p  60fps'` |
| `color` | цвет линий и текста | `#dedede` |
| `dot` | точка у REC: `'circle'` (●, как в ТЗ) или `'square'` (как в примере) | `'circle'` |
| `blink` | период мигания точки, с (горит первую половину, отсчёт от `start`; 0 — не мигает) | 1 |
| `center` | перекрестье в центре кадра | `true` |
| `battery` | значок батареи справа снизу | `false` |
| `scale` | масштаб всех элементов | 1 |

Разметка (1080p): перекрестья в точках (48, 48) от углов, плечо 88 px, линия 2 px; точка REC 26 px с центром
(87, 88), `REC` 34 px с x = 114; тайм-код 36 px, правый край x = 1836; подпись 28 px, x = 80, центр y = 998.

Помощники: `formatTimecode(83.4167)` → `"00:01:23.416"`; `useInterFont()` — хук, задерживающий кадр до загрузки
Inter (латиница + кириллица, 300/400/500), для любых своих DOM-надписей шрифтом `UI_FONT`
(`"Inter, 'Helvetica Neue', Arial, sans-serif"`).
