# ОПОЗДАЛ НА ВАЙП

Ролик для канала **1DEX1**: 30 секунд, 1920×1080, 60 fps. Кинематографичная Minecraft-анимация со скином 1DEX1:
пришёл из школы в 16:00, а вайп на HolyWorld был в 13:00 — бросает вещи, бежит к компьютеру, запускает Minecraft,
Discord и OBS и начинает запись. Сделан на [Remotion](https://www.remotion.dev/) + three.js, весь код на TypeScript.
Всё в кадре — настоящее 3D из кубов, без голоса: картинка, надписи, оригинальные звуки Minecraft и музыка
из нотных блоков.

- `SPEC.md` — сюжет, тексты, тайминг и правила.
- `CORE_API.md` — справочник движка для авторов сцен.

## Запуск

Нужен Node.js 18 или новее (и `ffmpeg` в системе; если его нет, возьмётся тот, что идёт с Remotion).

```bash
npm install
npm run dev      # предпросмотр в браузере (Remotion Studio)
npm run render   # готовое видео: out/opozdal-na-vaip.mp4
```

Обе команды сначала скачивают звуки Minecraft с официальных серверов Mojang в `public/sounds/`
и сводят дорожку `public/audio/soundtrack.wav`. В репозитории самих звуков нет — это ассеты Mojang.

Рендер по умолчанию программный и работает на любом компьютере. С видеокартой можно быстрее:
`npm run render -- --gl=angle-egl`.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run typecheck` | проверка типов |
| `npm run shots -- --scene=<id> 1 2.5` | кадры сцены в `out/shots/<id>/` (`--sheet` — контактный лист, `--bench` — замер) |
| `npm run preview -- --scene=<id>` | быстрый mp4 одной сцены со звуком в `out/preview/` |
| `npm run sounds` | скачать звуки (`-- --find <слово>` — поиск имён) |
| `npm run mix` | свести дорожку (`-- --scene=<id>` — одну сцену в `out/audio/`) |
| `npm run audio` | звуки + сведение |

## Что где

| Что | Где |
| --- | --- |
| Тайминг сцен, fps, размер кадра | `src/timeline.ts` |
| Сцены (камера, мир, интерфейс, звуки) | `src/scenes/<id>/` |
| Общие миры для нескольких сцен | `src/sets/<name>/` |
| Музыка | `src/music/score.ts` |
| Движок: воксели, персонажи, частицы, надписи | `src/core/` |
| Скин героя / логотип сервера | `public/skin.png`, `public/holyworld.png` |
| Скрипты (кадры, превью, звук) | `scripts/` |

Текстуры блоков, предметы и пиксельный шрифт нарисованы кодом. Служебные сцены в `src/scenes/_*`
(образец сцены, галереи окружений и поз, проверка шрифта, замер скорости) в ролик не входят.
