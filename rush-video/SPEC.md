# «ОПОЗДАЛ НА ВАЙП» — ТЗ ролика (30 секунд)

Ролик для ютубера **1DEX1** (Minecraft, канал и ТГК «Жизнь 1DEX1»). Короткая кинематографичная Minecraft-анимация
с его скином: он приходит из школы уставший в 16:00, видит, что вайп на HolyWorld был в 13:00, в панике бросает
вещи, бежит к компьютеру, запускает Minecraft, Discord и OBS и начинает запись.

Это единственный источник правды. Движок и инструменты описаны в `CORE_API.md` (движок перенесён из прошлого
проекта `../wipe-video`, его трогать нельзя — только читать).

---

## 1. Факты и тексты

- Суббота, **21 ноября**. Вайп на сервере **HolyWorld** (режим **Лайт Анархия**) был в **13:00**.
- Герой пришёл из школы в **16:00** → опоздал на **3 часа**.
- Сервер: `mc.holyworld.ru`. Ник героя: `1DEX1`.
- Скин героя — `public/skin.png` (тонкие руки; чёрные волосы с чёлкой, фиолетовая клетчатая рубашка/худи).

Тексты в кадре — ТОЛЬКО эти (регистр и знаки — как здесь; ё обязательно):

| где | текст |
|---|---|
| титр в первом плане | `СУББОТА · 21 НОЯБРЯ` |
| часы в прихожей | `16:00` |
| записка/календарь | `21 НОЯБРЯ`, `ВАЙП HOLYWORLD`, `13:00` (обведено красным) |
| шок | `Я ОПОЗДАЛ НА 3 ЧАСА?!` |
| рабочий стол | `Minecraft`, `Discord`, `OBS Studio` |
| Minecraft | `Сетевая игра`, `HolyWorld`, `mc.holyworld.ru`, `Лайт Анархия · ВАЙП`, `Подключиться` |
| Discord | сервер `1DEX1`, каналы `общий` (текстовый) и `запись` (голосовой), участник `1DEX1` |

| финал | `ПОГНАЛИ НА ВАЙП!`, ниже мельче `HolyWorld · Лайт Анархия` |

Никаких других надписей, логотипов, водяных знаков, упоминаний ИИ. Логотипы Discord/OBS/Minecraft не копировать —
рисовать упрощённые узнаваемые пиксельные значки (фиолетовый «геймпад-смайлик» в круге, тёмный круг с тремя
точками, блок травы). Логотип сервера — `public/holyworld.png` (можно на постере и в списке серверов).

## 2. Тайминг

Ролик 30.0 с, 1920×1080, 60 fps. Две сцены (`src/timeline.ts`, длительности не менять):

| сцена | глобально | локально | что |
|---|---|---|---|
| `a-home` | 0.0–16.0 | 0–16 | прихожая: пришёл, устал, часы, записка, шок, бросает вещи, бег наверх |
| `b-room` | 16.0–30.0 | 0–14 | комната: кресло, включение ПК, Minecraft, Discord, наушники, OBS, запись |

**Музыкальная сетка.** С 9.6 с идёт быстрая музыка 150 BPM: доля = 0.4 с, такт = 1.6 с. Все склейки после 9.6 —
на долях, то есть на ГЛОБАЛЬНЫХ временах, кратных 0.4 (9.6, 10.0, 10.4 … 16.0 … 29.6, 30.0). Важные удары
(бросок рюкзака, распахнутая дверь, клик «Начать запись», «ПОГНАЛИ») — тоже на долях.

## 4. Визуальный стиль

Ориентир — пример пользователя (кадры: `.tmp/reference/*.png`, лист: `.tmp/reference/contact-sheet.png`; в git не
коммитятся). Кинематографичная Minecraft-анимация в духе Blender/Mine-imator:

- Тёплый тёмный интерьер: ель/тёмный дуб, книжные полки, кирпич, ковры, фонари и свечи. Контраст, глубокие тени,
  тёплые блики (свет фонарей запечён в блоки), из окон — холодный/закатный свет.
- **Малая глубина резкости** на крупных и средних планах (фон заметно размыт), лёгкое свечение ярких источников,
  виньетка, слабое плёночное зерно, тёплая цветокоррекция. Возможно, лёгкая «ручная» тряска камеры (детерминированная).
- Камера живая: медленные наезды на эмоциях, резкие наезды/рывки на шоке и в беге, повороты-«вжух» на склейках.
- Персонаж выразительный: позы, наклоны, вторичные движения. Лицо меняет выражение (накладка поверх скина:
  усталые полуприкрытые глаза, моргание, шок — распахнутые белые глаза с маленькими зрачками и рот «О»,
  решимость — прищур, радость — глаза «^^» и улыбка). Скин при этом узнаваем.
- Надписи — пиксельный шрифт ядра (`PixelText`, Pixelify Sans) с обводкой/тенью; для интерфейсов ПК можно чистый
  гротеск с кириллицей (шрифт ставить из npm, `@fontsource/...`, в `public/fonts/`).
- Интерфейсы на экране (рабочий стол, Minecraft, Discord, OBS) — упрощённые, но правдоподобные, читаемые; рисуются кодом
  как чистая функция времени.
- В кадре нет HUD (сердец, хотбара), нет ника над головой.

## 5. Звук

- Эффекты — только оригинальные звуки Minecraft (`npm run sounds -- --find <слово>`), события в `sfx.ts` сцен,
  время синхронно с картинкой (из `beats.ts`).
- Музыка — своя, из нотных блоков (`src/music/score.ts`, глобальное время): 0–8.0 тихая грустная (арфа/колокольчики,
  минор, медленно), 8.0–9.6 пауза + удар, 9.6–29.6 быстрый энергичный трек 150 BPM (бочка/снейр/хэт + бас +
  мелодия), 29.6–30 финальный аккорд. Музыка тише эффектов, эффекты читаются.
- Итог сводится `npm run audio` в `public/audio/soundtrack.wav` (пик −1 дБ).

## 6. Технические правила

- Кадр — чистая функция времени (никаких `Math.random`, `Date`, `useFrame`, состояния). См. `CORE_API.md` §2, §17.
- Производительность: кадр 1920×1080 — не дольше ~1.5 с (`npm run shots -- --scene=<id> --bench <t>`).
- Владение файлами: каждый автор правит только свои папки (указаны в задании). Чужие файлы — только читать.
- Тайминг — в `beats.ts` сцены; звуки — в `sfx.ts` (чистый модуль).
- Комментарии в коде — по-русски, кратко. Никаких упоминаний ИИ ни в коде, ни в кадре.
- Авторы не делают git-коммитов (их делает ведущий).

## 7. Самопроверка автора

`npm run typecheck` без ошибок в своих файлах; контактные листы и полноразмерные кадры ключевых моментов
(`npm run shots`) просмотрены глазами; `npm run preview -- --scene=<id>` собирается; звуки скачиваются
(`npm run sounds`) и сводятся (`npm run mix -- --scene=<id>`).
