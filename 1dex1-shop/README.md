# 1DEX1 SHOP

Сайт-магазин ютубера 1DEX1: моды и ресурс-паки для Minecraft.
Обычные HTML, CSS и JavaScript — без сборки и без сервера. Работает на любом
хостинге статических сайтов, например GitHub Pages.

## Как открыть у себя

Сайт нужно открывать через локальный сервер (двойной клик по `index.html`
не сработает: браузер не загрузит скрипты).

```bash
cd 1dex1-shop
python3 -m http.server 8000
```

Потом открой в браузере `http://localhost:8000`.

## Что есть на сайте

- **Первый экран в 3D.**
  - Остров сам качается на 90° в каждую сторону, персонаж стоит на нём и
    качается вместе с ним. Мышь на остров не влияет.
  - На фоне медленно вращается галактика.
  - Название «1DEX1» висит на месте; блоки ломаются кликом и через 3 секунды
    вырастают.
  - **Добыча.** Клик по блоку острова: персонаж идёт к сундуку, берёт кирку,
    добывает блок (если дотянется), кладёт кирку обратно и возвращается.
    Пока одно действие не закончено, второе не начнётся. Блок вырастает через
    5 секунд.
  - **Кирки.** Камень даёт каменную кирку, железо — железную, алмаз — алмазную.
    Железо добывается только каменной киркой, алмазы и золото — железной.
    Уголь зажигает факелы на дереве (до четырёх). Прогресс сохраняется в браузере.
  - **Персонаж вне острова.** Его можно снять с острова: он летает в невесомости
    поверх сайта. Поднесённый к тексту или кнопке, тянется к ним и садится,
    ложится, приседает, стоит или машет. Над островом — спрыгивает на траву
    и идёт на своё место.
  - **Стена.** Бегущая строка «Магазин · Моды · РП» держит персонажа в первом
    экране. С алмазной киркой кликни по ней: персонаж возьмёт кирку, прилетит,
    сломает стену и сможет летать по всему сайту.
- **Магазин** с вкладками «Всё / Моды / РП». Сейчас товаров нет, стоит заглушка.
- **Каналы**: YouTube и Telegram с твоей аватаркой.
- **Аккаунт**: регистрация, вход, выход, смена пароля, аватарка из галереи
  (наведи на аватарку), баланс с историей. За все 10 достижений — 5 ₽ на баланс.
- **Достижения**: 8 обычных и 2 секретных.
- **Подвал**: надпись «1DEX1 SHOP» из блоков, которые тоже ломаются.
- На телефоне снизу панель-хотбар.

## Важно про аккаунты

У сайта пока нет сервера, поэтому аккаунты хранятся в браузере посетителя.
Это значит:

- аккаунт, созданный на телефоне, не виден на компьютере;
- ты не видишь, кто зарегистрировался;
- пополнить баланс нельзя: на него приходит только награда за достижения.

Чтобы аккаунты стали настоящими, нужен сервер или сервис вроде Firebase.
Весь код аккаунтов лежит в одном файле `js/auth.js` — менять придётся только его.

## Как менять содержимое

Содержимое лежит в `js/data.js`:

| Что | Где в `js/data.js` |
| --- | --- |
| Ссылки на YouTube и Telegram, контакт для рекламы | `SITE` |
| Слова в бегущей строке | `MARQUEE` |
| Товары: название, описание, цена, картинка, ссылка | `PRODUCTS` |

### Как добавить товар

В `PRODUCTS` уже лежит закомментированный пример. Скопируй его внутрь
квадратных скобок, убери `//` в начале строк и поменяй поля:

```js
{
	id: 'mod-kill-animation',   // любое уникальное имя латиницей
	kind: 'mod',                // 'mod' — мод, 'rp' — ресурс-пак
	status: 'ready',            // 'soon' — в разработке, 'ready' — готов
	title: 'Анимация килла',
	desc: 'Короткое описание в одну-две строки.',
	tags: ['1.21', 'Fabric'],
	price: 99,                  // число в рублях или null
	cover: 'img/kill-animation.png', // картинка 16:10 или null
	link: 'https://…',          // ссылка «Купить / Скачать» или null
},
```

Картинки клади в папку `img/`.

### Картинки

| Файл | Что это |
| --- | --- |
| `img/skin.png` | скин на первом экране (64×64, тонкие руки) |
| `img/avatar.jpg` | аватарка канала: в шапке и в карточках каналов |
