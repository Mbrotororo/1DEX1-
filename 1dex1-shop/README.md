# 1DEX1 SHOP

Сайт-магазин ютубера 1DEX1: моды и ресурс-паки для Minecraft.
Обычные HTML, CSS и JavaScript — без сборки и без сервера. Работает на любом
хостинге статических сайтов, например GitHub Pages.

## Как открыть у себя

Сайт нужно открывать через локальный сервер (двойной клик по `index.html`
не сработает: браузер не загрузит скрипты).

```bash
cd 1dex1-shop
python3 -m http.server 8000
```

Потом открой в браузере `http://localhost:8000`.

## Как менять содержимое

Всё, что видно на сайте, лежит в одном файле — `js/data.js`:

| Что | Где в `js/data.js` |
| --- | --- |
| Ссылки на YouTube и Telegram, IP сервера | `SITE` |
| Товары: название, описание, цена, картинка, ссылка | `PRODUCTS` |
| Ролики на главной | `VIDEOS` |
| Варианты в конструкторе идей | `IDEA` |
| Частые вопросы | `FAQ` |

### Как добавить товар

Скопируй любой блок в `PRODUCTS` и поменяй поля:

```js
{
	id: 'mod-kill-animation',   // любое уникальное имя латиницей
	kind: 'mod',                // 'mod' — мод, 'rp' — ресурс-пак
	status: 'ready',            // 'soon' — в разработке, 'ready' — готов
	title: 'Анимация килла',
	desc: 'Короткое описание в одну-две строки.',
	tags: ['1.21', 'Fabric', 'HolyWorld'],
	price: 99,                  // число в рублях или null
	cover: 'img/kill-animation.png', // картинка 16:10 или null
	link: 'https://…',          // ссылка «Купить / Скачать» или null
},
```

Пока `link` пустой, на карточке стоит кнопка «Хочу». Картинки клади в папку `img/`.

### Как добавить ролик

В `VIDEOS` добавь первой строкой: `id` — часть ссылки после `watch?v=`,
`title` и `duration`. Превью подтянется с YouTube само.

## Что есть на сайте

- Первый экран в 3D: парящий остров, твой скин, сундук и ник из блоков.
  Блоки ника ломаются кликом, со звуком.
- Магазин с вкладками «Всё / Моды / Ресурс-паки / Хочу».
- Конструктор идеи мода: копирует текст и открывает пост в Telegram.
- Последние ролики, карточка сервера с копированием IP, каналы, вопросы.
- Достижения в стиле Minecraft (хранятся в браузере посетителя).
- На телефоне снизу панель-хотбар.

## Что пока не сделано

Для этого нужен сервер, на статическом сайте оно не заработает:

- оплата и личный кабинет;
- вход через Telegram и проверка подписки;
- общий счётчик «Хочу» и голосование за идеи.

## Файлы

```
index.html          разметка страницы
css/style.css       оформление (цвета — в самом начале файла)
css/fonts.css       подключение шрифтов
js/data.js          всё содержимое сайта
js/app.js           магазин, идеи, ролики, достижения
js/hero.js          3D-сцена первого экрана
js/achievements.js  достижения
js/pixel.js         пиксельные иконки и обложки
vendor/             three.js (лицензия MIT)
fonts/              шрифты Rubik Mono One, Golos Text, Pixelify Sans (лицензия OFL)
img/                скин, логотип сервера, QR-код, иконка сайта
```

Чтобы сменить скин на первом экране, замени `img/skin.png` (64×64, тонкие руки).
