# 1DEX1 SHOP

Сайт-магазин ютубера 1DEX1: моды и ресурс-паки для Minecraft.
Обычные HTML, CSS и JavaScript — без сборки и без сервера. Работает на любом
хостинге статических сайтов, например GitHub Pages.

## Как открыть у себя

Сайт нужно открывать через локальный сервер (двойной клик по `index.html`
не сработает: браузер не загрузит скрипты).

```bash
cd 1dex1-shop
python3 -m http.server 8000
```

Потом открой в браузере `http://localhost:8000`.

## Что есть на сайте

- **Шапка.** Слева белая жирная надпись «1DEX1 SHOP» (под курсором пульсирует,
  на телефоне — от нажатия) и маленькое меню пиксельным шрифтом, как в Minecraft:
  Магазин · Сотрудничество · Кейсы · Каналы. Раздел на экране подчёркнут.
  На узких экранах меню прячется — там есть нижняя панель.
- **Нижняя панель-хотбар**: Главная · Магазин · Кейсы · Профиль. Рамка выделения
  переезжает на раздел, который сейчас на экране. На компьютере панель по центру
  внизу, как хотбар в игре, на телефоне — во всю ширину. Когда кейс можно открыть,
  на иконке кейса мигает точка.
- **Первый экран в 3D.**
  - Посередине — большая надпись «1DEX1 SHOP» из салатовых блоков: кубики смотрят
    прямо на зрителя, их можно ломать. Остров справа, кнопка «В магазин» — в левом
    нижнем углу.
  - Остров очень медленно поворачивается сам (на 60° в каждую сторону, туда и
    обратно — около двух минут), персонаж стоит на нём. Мышь на остров не влияет.
  - За островом галактика, а пиксельные звёзды по всему фону медленно вращаются
    вокруг её ядра.
  - **Добыча.** Клик по блоку острова: персонаж идёт к сундуку, открывает его,
    достаёт кирку и поднимает её, добывает блок (если дотянется), кладёт кирку
    обратно и возвращается.
    Пока одно действие не закончено, второе не начнётся. Блок вырастает через
    5 секунд.
  - **Кирки.** Камень даёт каменную кирку, железо — железную, алмаз — алмазную.
    Железо добывается только каменной киркой, алмазы и золото — железной.
    Уголь зажигает факелы на дереве (до четырёх). Прогресс сохраняется в браузере.
  - **Персонаж вне острова.** Его можно снять с острова: он летает в невесомости
    поверх сайта.
    - Сам находит рядом текст или кнопку и садится на них, свесив ноги. Потом
      меняет позы: болтает ногами, танцует, смотрит по сторонам, машет, лежит.
      Если долго не трогать — засыпает.
    - Над головой появляются эмоции в облачке («Привет!», «Уиии!», сердечко,
      нотки, «Zzz»).
    - Клик по нему — реагирует, но остаётся на месте. Потянуть — отлипает и
      висит в руке. Отпустить с размаху — улетает в ту сторону, кувыркается и
      плавно тормозит. Отпустить прямо над текстом — садится на него.
    - Когда листаешь страницу, летит следом и садится на то, что видно на экране.
    - Над островом спрыгивает на траву и идёт на своё место.
  - **Стена.** Бегущая строка «Магазин · Моды · РП» держит персонажа в первом
    экране. С алмазной киркой кликни по ней: персонаж возьмёт кирку, прилетит,
    сломает стену и сможет летать по всему сайту.
- **Магазин** с вкладками «Всё / Моды / РП». Сейчас товаров нет, стоит заглушка.
- **Кейсы**: ежедневный кейс, открывается раз в 24 часа в аккаунте. Награды:
  +5 ₽, +10 ₽ или +15 ₽ на баланс, самая редкая — купон на любой ресурс-пак
  бесплатно (он появляется в профиле). Шансы и награды — в `js/data.js` (`CASE`).
- **Сотрудничество**: виджет с уголками — личный профиль @RodionDex для рекламы.
  Вокруг аватарки в невесомости летают три значка визуалов (Aura, FadingVisual,
  Fantasy) и не вылетают за рамку: отталкиваются друг от друга, от аватарки и от
  краёв, подписи тоже не наезжают на аватарку. Значки чуть в тени; под курсором
  значок замирает, светлеет и увеличивается, клик открывает сайт визуала. Ник для
  связи — в `js/data.js` (`SITE.contact`), список визуалов — там же (`VISUALS`).
- **Каналы**: YouTube и Telegram с твоей аватаркой.
- **Аккаунт**: регистрация, вход, выход, смена пароля, аватарка из галереи
  (наведи на аватарку), баланс с историей. За все 10 достижений — 5 ₽ на баланс.
- **Достижения**: 8 обычных и 2 секретных.
- **Подвал**: надпись «1DEX1 SHOP» из блоков, которые тоже ломаются.
- **Скорость.** Второй холст для летающего персонажа создаётся, только когда его
  впервые снимают с острова. На телефонах и слабых устройствах 3D рисуется с
  меньшей чёткостью, а если в первые секунды сцена тормозит, чёткость снижается
  сама. Звёзды на фоне перерисовываются 30 раз в секунду, когда первый экран не
  виден, 3D-сцена не рисуется. Размытие под шапкой — только на компьютере.

## Важно про аккаунты

У сайта пока нет сервера, поэтому аккаунты хранятся в браузере посетителя.
Это значит:

- аккаунт, созданный на телефоне, не виден на компьютере;
- ты не видишь, кто зарегистрировался;
- пополнить баланс нельзя: на него приходят только награды за достижения и кейс;
- баланс, кейс и купоны живут в браузере, поэтому опытный посетитель может их
  подделать. Пока это не настоящие деньги, это не страшно. Перед подключением
  оплаты награды из кейса должен выдавать сервер (функция `openCase` в `js/auth.js`).

Чтобы аккаунты стали настоящими, нужен сервер или сервис вроде Firebase.
Весь код аккаунтов лежит в одном файле `js/auth.js` — менять придётся только его.

## Как менять содержимое

Содержимое лежит в `js/data.js`:

| Что | Где в `js/data.js` |
| --- | --- |
| Ссылки на YouTube и Telegram, личный Telegram для рекламы | `SITE` |
| Визуалы в «Сотрудничестве»: название, сайт, логотип | `VISUALS` |
| Слова в бегущей строке | `MARQUEE` |
| Ежедневный кейс: награды, шансы, как часто | `CASE` |
| Товары: название, описание, цена, картинка, ссылка | `PRODUCTS` |

### Как добавить товар

В `PRODUCTS` уже лежит закомментированный пример. Скопируй его внутрь
квадратных скобок, убери `//` в начале строк и поменяй поля:

```js
{
	id: 'mod-kill-animation',   // любое уникальное имя латиницей
	kind: 'mod',                // 'mod' — мод, 'rp' — ресурс-пак
	status: 'ready',            // 'soon' — в разработке, 'ready' — готов
	title: 'Анимация килла',
	desc: 'Короткое описание в одну-две строки.',
	tags: ['1.21', 'Fabric'],
	price: 99,                  // число в рублях или null
	cover: 'img/kill-animation.png', // картинка 16:10 или null
	link: 'https://…',          // ссылка «Купить / Скачать» или null
},
```

Картинки клади в папку `img/`.
