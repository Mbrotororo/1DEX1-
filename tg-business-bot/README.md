# 1DEX1 Business Bot

Личный Telegram-бот для личных чатов (как в ТикТоке): пишешь `.mut` в переписке —
собеседник в муте, его сообщения удаляются. Плюс цветочки, сердечки, спам и т.д.

Работает через официальный **Telegram Business** (нужен **Telegram Premium**).

## Команды (пишутся прямо в чате с человеком)

| Команда | Что делает |
|---|---|
| `.mut` | мут навсегда — все сообщения собеседника удаляются |
| `.mut 10m` / `2h` / `1d` | мут на время |
| `.unmut` | снять мут |
| `.mutes` | список замученных (придёт тебе в личку от бота) |
| `.flowers` | анимированный букет 💐 |
| `.love` | анимированные сердечки ❤️ |
| `.type текст` | печатает текст по буквам |
| `.spam 10 текст` | отправить текст N раз (максимум 30) |
| `.spamflowers 10` | спам цветочками |
| `.dice` / `.coin` | кубик / монетка |
| `.clear` | удалить всё, что бот отправил в этом чате |
| `.help` | справка (придёт в личку от бота) |

Сама команда сразу удаляется, собеседник её не видит.
Ещё бот присылает тебе в личку **удалённые и изменённые** сообщения собеседника.

## Запуск

1. В [@BotFather](https://t.me/BotFather): `/newbot` → получи токен.
   Потом `/mybots` → твой бот → **Bot Settings → Business Mode → Turn on**.
2. Установи и запусти:
   ```bash
   cd tg-business-bot
   python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   cp .env.example .env        # вставь туда BOT_TOKEN
   python bot.py
   ```
3. Напиши боту `/start` (чтобы он мог слать тебе уведомления).
4. В Telegram: **Настройки → Telegram Business → Чат-боты** → введи @username бота →
   включи права **«Отвечать на сообщения»** и **«Удалять все сообщения»**.
5. Открой любой личный чат и напиши `.help`.

Бот должен работать постоянно (на ПК или хостинге/VPS), иначе команды не сработают.
Мьюты сохраняются в `data.json`.
