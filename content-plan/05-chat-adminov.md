# Ролик №5 «Чат админов»: сценарий

Вертикальная страшилка, 60 с, 1080×1920, 30 fps. Это идея №5 из `PLAN.md`.
Из референсов взята только формула: хук, 2–4 слова на экране, правило и его нарушение, твист.
Картинка в стиле интерфейса Minecraft, звуки из Minecraft.

- Код: `fantasy-flood-video/src/admin-chat/`
- Тексты и тайминги: `script.ts`
- Рендер: `cd fantasy-flood-video && npm install && npm run render:admin` → `out/1dex1-admin-chat.mp4`

## Озвучка

В ролике нет голоса: историю рассказывают субтитры и чат, как в формате переписки. Если захочется озвучить:
текст для диктора — это субтитры подряд, темп примерно 150 слов в минуту, все тайминги уже под него.
Готовую дорожку положить в `public/admin-chat/voice.mp3` и добавить `<Audio>` в `AdminChat.tsx`.
