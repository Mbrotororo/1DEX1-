# «Чат админов»: текст для озвучки

Текст совпадает с субтитрами, поэтому голос сразу ляжет на готовое видео.
Время в скобках — когда фраза начинается в ролике и сколько секунд на неё есть.

Как читать:

- Голос тихий и ровный, как будто рассказываешь ночью. Не кричать.
- `/` — короткая пауза, `//` — пауза подлиннее.
- Слова *курсивом* — это сообщения Кости. Их можно прошептать или наложить эффект рации.
- **Жирное** — ударные слова, на них чуть надавить.
- «1DEX1» читай так, как ты сам называешь свой ник.

---

**[0:00, 3.5 с]**
В чате админов / **одиннадцать** человек. // Нас — десять.

**[0:03.6, 6 с]**
Я — 1DEX1. / Держу сервер с друзьями. / Админов ровно **десять**. // Я считал.

**[0:10, 8 с]**
Каждую ночь в три / сервер уходит на рестарт. // Десять минут на нём **никого**. // Даже нас.

**[0:18, 6.5 с]**
Три ноль две. Новое сообщение. / От **Кости**. // Его забанили месяц назад. / Аккаунт — **удалён**.

*(0:24.6–0:26 — пауза, в чате пишут другие админы)*

**[0:26, 3.4 с]**
*«Я на спавне. / Факелы гаснут».*

*(0:29.4–0:30 — пауза, гаснет последний факел)*

**[0:30, 3.4 с]**
Захожу в консоль. // Онлайн: **ноль**.

**[0:33.4, 5 с]**
*«Тут кто-то стоит».* // *«У него / твой скин, 1DEX1».*

**[0:38.5, 6.5 с]**
Я не на сервере. / Я даже не в игре. // Но внизу пишет: / «1DEX1 **печатает**…»

*(0:45–0:48.6 — полная тишина, потом скример. Здесь ничего не говорить.)*

**[0:48.6, 2.4 с]**
Я это **не писал**.

**[0:51, 6.4 с]**
Утром Костя вышел. / Но нас всё ещё — **одиннадцать**. // И 1DEX1 / теперь **двое**.

**[0:57.4, 2.6 с]**
Подпишись, / пока ты в списке.

---

Всего около 120 слов, на это нужно примерно 50 секунд речи. По времени запас есть.
