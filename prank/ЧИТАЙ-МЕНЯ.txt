================================================================
  PRANK "FAKE VIRUS"  -  безобидная страшилка для ТВОЕГО компа
================================================================

ЧТО ЭТО
  Полноэкранная страшилка СО ЗВУКОМ: матрица, фейковый хакерский
  терминал (ACCESS GRANTED, STOLEN, rm -rf - всё ФЕЙК), череп,
  зелёный "взлом"-глитч, жуткий гул/сирена, красные надписи
  "YOU HAVE BEEN HACKED / Ты взломан", фейк "ENCRYPTING FILES".
  Идёт 60 секунд и само успокаивается.
  НИЧЕГО не ворует и не ломает. Окна только сворачиваются.

ФАЙЛЫ
  START.bat                  - запустить прикол вручную (двойной клик)
  scare.html                 - сама страшилка
  autorun-watcher.vbs        - "сторож" для автозапуска по флешке
  УСТАНОВИТЬ-автозапуск.bat   - включить автозапуск по вставке флешки
  УДАЛИТЬ-автозапуск.bat      - убрать автозапуск полностью

================================================================
 СПОСОБ 1 - просто запустить (самое надёжное)
================================================================
  Вставил флешку -> открыл -> двойной клик по START.bat.
  Окна свернутся, прикол откроется сам на весь экран со звуком.

================================================================
 СПОСОБ 2 - "вставил флешку и САМО запустилось"
================================================================
  Делается ОДИН раз на ТВОЁМ компе:

  1) Назови свою флешку  PRANK :
     Этот компьютер -> правый клик по флешке -> Переименовать -> PRANK
  2) На флешке запусти  УСТАНОВИТЬ-автозапуск.bat  (двойной клик).
  3) Всё. Теперь КАЖДЫЙ раз, когда ты вставляешь эту флешку (метка
     PRANK) в ЭТОТ комп - прикол запускается сам.

  Чтобы выключить автозапуск: запусти  УДАЛИТЬ-автозапуск.bat

  ВАЖНО и ЧЕСТНО:
   * Работает ТОЛЬКО на том компе, где ты нажал УСТАНОВИТЬ.
     На школьном/чужом компе НЕ сработает - там ничего не стоит.
     (Поэтому так нельзя пугать чужие ПК - и это правильно.)
   * Настоящего "autorun с любой флешки на любом ПК" не существует:
     Windows его отключила против вирусов. "Само на любом компе" =
     это уже настоящий вирус или спец-железка, такое НЕ делаем.

================================================================
 ЗАКРЫТИЕ (первые 60 секунд закрыть нельзя)
================================================================
  Пока идёт прикол: Esc, F11, правый клик, закрытие вкладки - всё
  заблокировано. Через 60 сек разблокируется само.

  ТОЛЬКО ДЛЯ ТЕБЯ (друзья не знают) - аварийный выход:
      Ctrl + Shift + Q   -> мгновенно выключить
      Alt + F4           -> крайний случай (работает всегда)

  Вернуть свёрнутые окна после прикола:  Win + Shift + M
