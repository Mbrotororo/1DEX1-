ЧТО ЭТО
  Полноэкранная страшилка С ТВОЕЙ МУЗЫКОЙ: матрица, фейковый
  хакерский терминал (ACCESS GRANTED, STOLEN, rm -rf - всё ФЕЙК),
  череп, зелёный "взлом"-глитч, красные надписи "YOU HAVE BEEN
  HACKED / Ты взломан", фейк "ENCRYPTING FILES".
  Идёт 60 секунд и само успокаивается.
  НИЧЕГО не ворует и не ломает. Окна только сворачиваются.

  ВАЖНО: теперь это запускается как ПРОГРАММА на ПК (формат .hta,
  через встроенный Windows mshta.exe) - НЕ в браузере, НЕ в Google.
  Своё окно, без адресной строки.

ФАЙЛЫ
  scare.hta                  - САМА программа (двойной клик = запуск)
  track.mp3                  - твоя музыка
  START.bat                  - свернуть окна + запустить (рекомендую)
  scare.html                 - запасной вариант для браузера
  autorun-watcher.vbs        - "сторож" для автозапуска по флешке
  УСТАНОВИТЬ-автозапуск.bat   - включить автозапуск по вставке флешки
  УДАЛИТЬ-автозапуск.bat      - убрать автозапуск полностью

================================================================
 СПОСОБ 1 - просто запустить (как программу, не браузер)
================================================================
  Вариант А: двойной клик по  scare.hta  -> откроется своим окном
             на весь экран, с музыкой.
  Вариант Б: двойной клик по  START.bat  -> сначала свернёт все
             окна, потом запустит scare.hta (эффект сильнее).

  Если Windows спросит "Чем открыть .hta" - выбери
  "Microsoft (R) HTML Application host" (mshta). Он встроен в Windows.

================================================================
 СПОСОБ 2 - "вставил флешку и САМО запустилось"
================================================================
  Делается ОДИН раз на ТВОЁМ компе:
  1) Назови свою флешку  PRANK :
     Этот компьютер -> правый клик по флешке -> Переименовать -> PRANK
  2) На флешке запусти  УСТАНОВИТЬ-автозапуск.bat
  3) Готово. Теперь каждый раз, когда вставляешь эту флешку (метка
     PRANK) в ЭТОТ комп - прикол (scare.hta) запускается сам.
  Выключить автозапуск:  УДАЛИТЬ-автозапуск.bat

  ЧЕСТНО: работает ТОЛЬКО на том компе, где нажал УСТАНОВИТЬ.
  На школьном/чужом ПК НЕ сработает - там ничего не стоит.
  Настоящего "autorun с любой флешки на любом ПК" не существует
  (Windows его отключила против вирусов).

================================================================
 ЗАКРЫТИЕ (первые 60 секунд закрыть нельзя)
================================================================
  Пока идёт прикол: Esc, F11, правый клик, закрытие окна -
  заблокированы. Через 60 сек разблокируется само.

  ТОЛЬКО ДЛЯ ТЕБЯ (друзья не знают) - аварийный выход:
      Ctrl + Shift + Q   -> мгновенно выключить
      Alt + F4           -> крайний случай (работает всегда)

  Вернуть свёрнутые окна после прикола:  Win + Shift + M
