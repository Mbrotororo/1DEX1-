# Luma

**Luma** — рабочий стол (лаунчер) для Android в стиле «жидкого стекла», как в iOS 26.
Он заменяет обычный экран «Домой» телефона: стеклянные часы с приветствием, сетка
приложений, стеклянный док, поиск и полный список приложений. Всё стекло живое:
оно размывает обои, преломляет свет по краям и ловит блики, когда вы наклоняете телефон.

Сделано для 1DEX1.

## Что умеет

- **Экран «Домой»:** стеклянный виджет часов (время, дата, заряд батареи и приветствие
  «Доброе утро / Добрый день / Добрый вечер / Доброй ночи» с вашим именем), сетка
  приложений, капсула «Поиск» и док на 4 приложения.
- **Жесты:** смахните вверх, чтобы открыть все приложения. Смахните вниз, чтобы открыть
  шторку уведомлений. Удерживайте значок, чтобы открыть меню: «Убрать с экрана» /
  «На экран Домой», «В док» / «Убрать из дока», «О приложении», «Удалить». Удерживайте
  пустое место, чтобы открыть «Обои» и «Настройки Luma».
- **Список приложений:** все приложения по алфавиту и поиск по мере ввода. Кнопка
  «Ввод» на клавиатуре запускает первое найденное приложение.
- **Настройки Luma:** готовые стили стекла (Прозрачное, Иней, Дым, Неон, Бункер, Океан),
  размытие, прозрачность, яркость края, скругление, оттенок, жидкое преломление
  (Android 13 и новее) и блики при наклоне. Здесь же выбираются обои: шесть встроенных
  или своё фото из галереи; любые обои можно поставить и как обои системы. Ещё есть
  стиль значков (Оригинал, Стекло, Прозрачные), их размер, подписи, 4 или 5 колонок,
  имя для приветствия, часы и поиск. Все изменения видны сразу.
- **Кнопки:** «Назад» закрывает открытое окно, но не выходит с рабочего стола. «Домой»
  возвращает на главный экран.

## Как установить на телефон

1. Скопируйте файл `release/Luma.apk` на телефон: через USB-кабель, Telegram «Избранное»,
   Google Диск или любым другим способом.
2. Откройте файл на телефоне, например в приложении «Файлы» или прямо из Telegram.
3. Android попросит разрешить установку из неизвестных источников. Нажмите
   **«Настройки»**, включите **«Разрешить из этого источника»** и вернитесь назад.
   На разных телефонах пункт называется по-разному:
   - Samsung: «Установка неизвестных приложений»;
   - Xiaomi: «Неизвестные источники»;
   - на старых Android (7 и ниже): «Настройки → Безопасность → Неизвестные источники».
4. Нажмите **«Установить»**. Если появится предупреждение Google Play Защиты, выберите
   «Всё равно установить»: приложение собрано не через Google Play, поэтому система его
   не знает.

Нужен Android 8.0 или новее.

## Как сделать Luma рабочим столом

**Способ 1: из самого приложения.** При первом запуске Luma покажет приветствие.
Нажмите **«Сделать рабочим столом»** и выберите Luma в системном окне. Позже то же самое
можно сделать в «Настройках Luma» кнопкой **«Сделать Luma рабочим столом»**.

**Способ 2: через настройки телефона.**

- Чистый Android и Pixel: «Настройки → Приложения → Приложения по умолчанию →
  Главный экран» (или «Приложение для главного экрана»), затем выберите **Luma**.
- Samsung: «Настройки → Приложения → Выбор приложений по умолчанию → Главный экран».
- Xiaomi / Redmi / POCO: «Настройки → Приложения → Приложения по умолчанию →
  Рабочий стол».

**Способ 3.** Нажмите кнопку «Домой». Если телефон спросит, чем открыть рабочий стол,
выберите **Luma** и «Всегда».

## Как вернуть старый рабочий стол

1. Откройте «Настройки Luma» (удерживайте пустое место на экране и выберите
   «Настройки Luma»).
2. Нажмите **«Выбрать другой рабочий стол»** и выберите прежний, например
   «Pixel Launcher», «One UI Home» или «Рабочий стол MIUI».

То же самое можно сделать в настройках телефона (см. способ 2 выше). Ещё один вариант:
удалить Luma. Тогда телефон сам вернётся к стандартному рабочему столу.

## Как собрать из исходников

Понадобятся JDK 17 или новее (проверено на JDK 21) и Android SDK (platform 35,
build-tools 35.0.0).

```bash
cd luma
# путь к Android SDK
echo "sdk.dir=/путь/к/android-sdk" > local.properties
./gradlew assembleRelease
# готовый файл: app/build/outputs/apk/release/app-release.apk
```

Своим ключом APK подписывается так: добавьте в `local.properties` (этот файл не попадает
в git) четыре строки:

```properties
LUMA_STORE_FILE=/путь/к/luma-release.jks
LUMA_STORE_PASSWORD=...
LUMA_KEY_ALIAS=luma
LUMA_KEY_PASSWORD=...
```

Без них release-сборка подписывается отладочным ключом. Ключ создаётся командой:

```bash
keytool -genkeypair -v -keystore luma-release.jks -alias luma \
  -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=1DEX1 Luma"
```

Не публикуйте файл ключа и пароли. Важно: обновление поверх установленной версии
работает, только если APK подписан тем же ключом.

### Устройство проекта

- `data/`: список приложений (`AppRepository`), раскладка экрана и дока (`LayoutStore`),
  настройки (`SettingsStore`, хранятся в SharedPreferences).
- `glass/`: движок стекла. Здесь обои Luma, размытие (`StackBlur`), AGSL-шейдер
  преломления для Android 13+ и `GlassRoot` / `GlassSurface`.
- `ui/`: экраны на Jetpack Compose (Домой, приложения, настройки, знакомство, меню).
  `LumaRoot` связывает их с данными. `LumaPreviewScene` показывает интерфейс на
  тестовых данных для превью и скриншот-тестов.
