# 1DEX1 Сканер

Веб-приложение для телефона: камера находит людей и рисует HUD.

- **Захват цели**: человек ближе 5 м обводится красной рамкой, дальше — зелёной (порог меняется в настройках).
- **Рост и возраст**: рост считается по камере и датчику наклона телефона, возраст определяет нейросеть по лицу.
- **Скан лица**: если поднести камеру к лицу, оно покрывается сеткой из 478 точек.
- **Скелет**: 33 точки тела, повторяет движения человека.
- **Запись видео и снимки** сохраняются прямо с HUD.

Всё считается на телефоне, видео никуда не отправляется.

## Как открыть

Камера в браузере работает только по HTTPS. Самый простой вариант — GitHub Pages:
Settings → Pages → Deploy from a branch → `main` / `(root)`.
После этого сканер будет доступен по адресу `https://<ник>.github.io/<репозиторий>/scanner/`.

На телефоне открой ссылку в Chrome, затем в меню выбери «Добавить на главный экран» — сканер откроется на весь экран, как обычное приложение.

## Точность

- Рост: ±3–6 см, если человек стоит прямо и виден целиком, а в настройках указана правильная высота телефона над землёй. Точнее всего после калибровки по человеку с известным ростом.
- Дистанция: вблизи (до ~2 м) — по радужке глаза; дальше — по точке, где стопы касаются земли, и наклону телефона.
- Возраст: примерный, ошибка ±5–8 лет.
- Знак `≈` в HUD означает грубую оценку (например, когда не видно ног).

## Устройство

| Файл | Что делает |
| --- | --- |
| `js/main.js` | камера, цикл кадров, кнопки, настройки, калибровка |
| `js/models.js` | загрузка MediaPipe (тело, лицо) и face-api (возраст) |
| `js/geometry.js` | датчик наклона, дистанция, рост |
| `js/tracker.js` | номера целей между кадрами, сглаживание |
| `js/render.js` | отрисовка видео, скелета, сетки лица, рамок и HUD |
| `js/age.js` | вырезка лица и оценка возраста |

Для проверки без камеры: `index.html?test=<url видео>`.
